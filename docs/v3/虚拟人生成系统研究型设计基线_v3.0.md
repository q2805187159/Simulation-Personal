# 虚拟人生成系统：研究型设计基线 v3.0

跨模块的标准术语、数据链路、图修订及运行契约见[全链路设计复核与统一契约](全链路设计复核与统一契约.md)。LLM 的生成、修订、填充、审查和人物问答职责见[LLM 人生生成与数字人问答设计](LLM人生生成与数字人问答设计.md)。本基线提供各领域的生成与验收依据。

**状态：** 研究型设计基线，供后续产品、数据与工程设计使用  
**资料复核日期：** 2026-09-29  
**目标：** 生成覆盖中国各地区、民族与多样社会处境的合成人物及其完整人生，使下游 AI/Agent 能依据人物在特定时间、情境和知识边界下完成问卷、访谈和行为模拟。  
**边界：** 人物是合成研究对象，不是真实调查受访者，不代表任何具体个人，也不能仅凭“像人”推断其可替代真实样本。

## 1. 设计立场

### 1.1 真正要生成什么

目标不是“填满一张人物卡”，而是生成一个在时间中生活的人：有身体和能力，有关系和责任，有可获得但有限的信息，有习得的习惯、价值冲突、记忆与遗忘，有受制度、资源和偶然事件影响的选择；同一个人在不同年份、关系视角和问卷情境中应保持可解释的一致性，也允许成长、矛盾和遗忘。

最终产物是可供其他系统调用的**带时间、证据与权限的人生档案**。同一份事件账本支持事实回放、人物当时的经验、后来形成的回忆以及一次具体作答。人要经历得通，档案要查得回，角色也应当有权不知道、记错或保持沉默。

### 1.2 第一性原理

1. 人不是静态属性向量。属性、能力、关系、资源、记忆和环境会共同作用并随时间变化。
2. 人生不是宏观事件的自动结果。历史提供暴露、约束和机会；个人是否接触、如何理解、如何反应都存在差异。
3. 人的状态不能由身份标签直接推出。民族、性别、地域、阶层、年龄等只提供人口学条件或生活情境的概率信息，不是人格、信仰、政治态度、语言能力或行为的决定规则。
4. “无逻辑漏洞”只是最低门槛。还必须检验群体分布、变量关系、人生机制、跨题行为和对真实样本的外部预测能力。
5. 任何模拟结论都要带适用范围。某个合成样本通过人口边际校准，并不意味着它能模拟未校准的价值观、少数群体经验或因果效应。
6. 需要区分“模型知道什么”和“人物知道什么”。系统的历史知识不能自动变成角色亲历、个人记忆或问卷答案。

### 1.2.1 争论如何改变设计

| 两种解释分别抓住什么 | 基线决策 | 什么会推翻设计假设 |
|---|---|---|
| 人口约束减少明显失真；人生路径的联合结构无法仅靠汇总分布还原 | 将当期边际、同人/家户联合分布和跨期转移分开校准。对同一边际容许多套联合假设，记录推断与敏感性。 | 若替换两套同样匹配边际的合理联合结构后，目标结论明显改变，该输出只能按情景报告。 |
| 历史与制度限定选择；相近条件的人仍会做出不同决定 | 对每个重大转折保存真实机会、人物当时认为的机会、可决定的人、申请/放弃/失败与实际结果。 | 同一政策下给两人不同获知或服务可达条件，生成器应保留差异。两人的结果一致时也要能回查各自路径。 |
| 长期倾向使人格可辨；行动受身体、处境、习惯与关系压力调节 | 分开较慢倾向、短期状态、角色目标、情境行为及自我解释，允许改变、长期稳定或有条件例外。 | 相同人物跨场景的选项完全固定，或同一场景重跑时彼此独立地改写人物状态，均触发复核。 |
| 自我叙事可组织经历；有人用零散片段或实际事务理解自己 | 结构化事实可回放，叙事允许不连贯、重释、没有中心主题。亲属义务与个人目标可同时成立。 | 同一事件必须支持多方解释，且删去一个人物的人生总结后仍可再现已定事实。 |
| 大事容易展示历史；大量时间花在日常和没有转折的阶段 | 维护并行区间与常态节律，只为决策、冲突和任务展开细节。亲历、常态和确定无事各有独立表述。 | 没有宏观冲击时仍应生成可对账的作息、家庭关系与资源变化；无须人为提高转折频次。 |
| 传记丰富可能帮助作答；多余细节、群体刻板印象与模型先验也会改变答案 | 按权限提供与题目相关的快照及先前会话。以同人物、同题、同模式消融传记，并同真人重测和统计基线比较。 | 细节增多若未改善留出题，或使小群体差距、选项顺序效应与方差收缩加剧，限制相应用途。 |

### 1.3 目标用途与限制

主要用途是后续项目中的 AI 受访者/人物代理，用于问卷流程测试、假设探索、访谈预演、分群与方案压力测试。建议支持三种明确模式：

| 模式 | 用途 | 输出解释 |
|---|---|---|
| 交互测试 | 测试问卷理解、跳题、可读性、极端输入与访谈脚本 | 适合发现流程问题，不表示真实人群意见 |
| 合成探索 | 对已有人群数据或理论机制做情景探索、生成候选解释 | 仅为模型生成的条件性结果，须显示假设和不确定性 |
| 外部验证 | 将合成人物对留出真实调查题作答，与真实样本比较 | 只有针对指定总体、题目、时间和误差标准通过后，才能声明相应适用性 |

不默认将合成人群作为真实概率样本的替代品；不以合成回答估计选举、公共政策、临床、金融或其他高影响人群结论，除非有研究设计、独立真实数据基准和明确审查支持。合成数据必须始终可识别为合成数据。

## 2. 目标人群边界与总体口径

“中国人/中国社会”需要成为可配置且可审计的总体定义，而不是一个没有口径的标签。建议首期人口框架区分：

- 中国大陆常住人口：按统计标准时点、常住地与相应调查总体定义。
- 香港、澳门、台湾地区居民：各自作为独立统计制度、时间口径和行政分类的数据域，再建立可比字段；不可把大陆样本框直接外推到三地。
- 海外华人/华侨及其他跨境迁移人口：单设侨居国/地区、出生地、国籍/身份、自我认同、代际、语言和迁移经历；缺乏可比数据时显式标为低覆盖，而不是用大陆经验补齐。
- 各民族与多重文化归属：保留来源口径、自我认同、家庭/社区实践与语言经历；人口普查所用民族分类可作一个行政统计变量，但不能当成全部文化身份。

每次生成声明 `frame_id`、纳入/排除与去重规则、参照日与时区、出生队列或年龄范围、观察截止日、地理及分类版本、用途与覆盖说明。出生地、户籍地、实际停留地、常住地、国籍或证件状态、族裔自认和行政统计分类分别在相应时点判断。一个人物可同时进入不同研究框架；合并框架前需证明覆盖交集及可用权重。全部地区和民族进入设计表示层。概率生成与加权发布按地区×时期×群体×主题逐格标记可校准、只支持机制、情景或不可评估。

| 生成入口 | 抽样对象 | 观察与输出边界 |
|---|---|---|
| 参照日存活人群 | 满足当日纳入规则的活人 | 人生前史以存活至参照日为条件。后续未观察阶段标为右删失；未来另起分支。 |
| 特定时期出生队列 | 对应时期及定义的人口出生 | 从出生推进，允许早夭、迁移、失访条件和超出观察窗的生存。 |
| 特定时期死者档案 | 指定范围内死亡的人或登记死亡 | 区分死亡发生期与登记期，按覆盖检查漏报，静态档案结束于死亡。 |
| 机制探索或弱覆盖组 | 按定义过采样或指定条件的合成人物 | 可测试罕见组合、语境和异常路径。只有具有入样概率和匹配证据时估计总体。 |

## 3. 核心对象模型：从“族×维度”到带时间的个人世界

原有“维度族”和“事件目录”保留为浏览入口；底层语义拆成相互关联的对象。每个字段有稳定 ID、定义、测量/生成方式和版本，不能把一个中文标签直接当作完整 schema。

### 3.1 对象

| 对象 | 表达内容 | 关键边界 |
|---|---|---|
| 人物 Person | 身份、出生/死亡、归属、生成批次、隐私等级 | 不把现实姓名、证件号、生物识别做成默认字段 |
| 状态快照 StateSnapshot | 某个有效时间点的状态，如居住地、工作、健康功能、资源与主观信念 | 每项区分有效时间与记录时间；状态可由事件投影重建 |
| 人生事件 LifeEvent | 发生/持续/结束的事件，及参与者、地点、作用对象、后果 | 允许日期区间、回忆日期不确定、资料日期与发生日期不同 |
| 并行轨迹 LifeSpell | 居住、教育、劳动、健康、关系、照料、资产与日常活动的起止区间 | 多轨可并行，有其一不自动终止其余；按角色、地点和资源校验互斥及覆盖 |
| 关系 Relationship | 亲属、伴侣、照料、同事、邻里、师友、机构关系 | 有方向、有效期、亲疏/支持/冲突等不同属性；双方叙述可不一致 |
| 家庭/群组 Household/Group | 家庭户、共同生活单元、工作组织、学校、社区、宗教/文化组织 | 家庭关系不等同于同住；户籍、居住、经济共同体分别表达 |
| 地点/制度 Place/Institution | 地理空间、学校、单位、制度、服务和组织 | 有行政区划/制度版本和适用时间；不把行政边界当文化边界 |
| 历史节点 HistoricalNode | 宏观历史、制度变更、地区事件、灾害、舆论与技术环境 | 记录暴露范围、作用机制及非确定性，不直接变成个人经历 |
| 暴露记录 Exposure | 某人或其关联方在某时地的适用性、渠道、强度和不确定性 | 直接、家庭/机构转导、仅获知、无暴露和未知的语义各自保存 |
| 行动候选与结果 Decision/Attempt | 可达及主观选项、决定者、尝试、失败、未选路径、结果反馈 | 候选可因风险竞争而失效。合成人物账本只写生效的尝试、经历和状态增量 |
| 认知/记忆 Cognition/Memory | 知识、信念、态度、目标、情绪、记忆内容与来源 | 区分当时状态、后来回忆、当前解释和外部史实 |
| 观测 Observation | 身体测量、自报、代答、登记与外部记录 | 观察者和被观察者可不同，原始值、测量限制、相互冲突和修订都有独立记录 |
| 问卷回答 SurveyResponse | 作答、信心、理解状态、回答动机、题目条件 | 绑定问卷版本、题目文本、作答时点、情境和使用的人物快照 |
| 证据/来源 Evidence/Provenance | 来源、抽样/推断/生成过程、支持对象、置信区间/等级 | “来源可溯”不等于合成个体是官方数据中的真实个体 |

### 3.1.1 人生事件图与节点细化

每个人物的人生记录由有版本的 `LifeGraph` 表达。事件节点带稳定 `event_id`、节点类型、有效时间区间、时间精度、参与主体、证据状态和生成来源。严格时间先后形成有向无环的部分序。重叠、并行、包含和顺序未知由区间关系表达。因果假设、参与关系、空间位置、历史暴露、证据支持、人物记忆、节点细化和重算依赖按各自语义记录。历史目录使用独立的 `historical_node_id`。

粗粒度事件被 LLM 拆分后，原节点保留稳定 ID 并转为汇总锚点，子事件使用新 ID，通过 `decomposes` 关系连接。标记为仅汇总的父节点不再次投影状态变化、重复结算资源或计入事件频数。动机、证据、记忆和叙事细节沿用对应对象和关系，不为丰富文字而伪造成已发生事件。供依赖重算使用的边另构成无环依赖图，与可含多类关系的事件图分开维护。

### 3.2 每个值的语义

对于会随时间变化或需要作为事实读取的字段，统一表达：

    value_id, subject_id, predicate_id, value, unit, valid_time, time_precision,
    recorded_at, supersedes_id, world_version, graph_revision_id, branch_id, provenance_id,
    applicability, determination_status, epistemic_status, confidence_or_range,
    privacy_class, visibility_policy, schema_version

每条属性分别记录概念适用性、合成世界中的确定性、观察结果和证据用途。确定性允许已确认、区间、未确定及冲突待解；证据类型含观察、总体统计、依分布抽样、规则推导、合成细节、人物记忆或自述、反事实及未来情景。合成世界中的确认只对该版本有效。诸如知情、愿意披露、剧本已展开、资料已登记和是否真实发生，属于彼此独立的判断。年龄、照护覆盖、家庭现金流等推导值保存输入版本及口径。

缺失值至少区分：未知、尚未收集、不适用、拒答/不愿说、资料冲突、暂不可见。粗时间精度持续传递到下游；只知出生年份时，不宜把某个跨月事件展示为精确周岁。基础属性抽样保存分布版本、种子与实际产物。候选人生事件保存触发条件、选项、校准状态、替代分支及被选择依据，无足够数据时不填写可作频率解释的数字。

### 3.2.1 四种时点与可见投影

| 时点 | 使用方式 |
|---|---|
| 事实或规则有效时间 `valid_time` | 表明何时发生、持续或可适用。支持起止、区间、精度与时区；日期、有效期、结算期按各自口径保存。 |
| 档案登记时间 `recorded_at` | 入库/修订追加新记录，经 `supersedes_id` 连接。审计读取 `archive_as_of` 时点已登记的版本，支持以新版重新查证旧事。 |
| 人物获知时间 `known_at` | 对每个人和信息项记录获知渠道、精度与信念。规则发布时间、当事人听说时间和实际施行时间可以不同。 |
| 作答时点 `response_at` 与回顾期 `reference_window` | 先取得作答时的人物快照与其可访问的回忆，再按题意筛选所问的历史区间。以往发生但作答以后方获知的事不能通过档案补录进入当时回答。 |

档案投影按世界/分支版本、查询有效时点 `as_of`、档案截止点 `archive_as_of` 筛选。查询历史人物时通常固定本次签发的档案版本，再按早年的角色时点查询；只有审计旧版入库结果时才把档案截止点也设置为过去。角色投影按实际说话者、当时已获知内容、披露对象与目的权限过滤，只把获准的数据交给回答模型。即使晚近史学材料修正了旧年份，历史模拟仍使用当事人当时能知道的内容。访问方没有权限时，既不能返回原值，也不能经来源摘要、跨人回查或引文泄漏该值。

**回放用例。** 一次离岗发生于 2001 年，人物在 2012 年回顾时记成 2002 年，档案于 2025 年补录。查 2001 年的新版档案可返回离岗，查 2025 年补录前的档案仍缺少该条记录。模拟 2012 年回答要回放当时已有的记忆，保持其误差。2025 年的补录只有经有记录的告知或查询才可能更新人物对往事的看法。

### 3.2.2 平常生活与共同事件如何记账

按人生阶段生成居住、就学、劳动、健康功能、关系、照料和资源的并行区间，给持久阶段保留工作日、休息日、农忙、夜班等有根据的常态。细化到可影响决策、冲突或问卷的日期与时段，未展开的日程继承区间边界。分开可并行活动和需要本人在场的排他任务，检查通勤、睡眠、现金/信贷、住房及工具能否同时满足。长期过载、照护落空和不能及时支付均是允许记录的结果。调查口径对比须先把模拟活动投影为相同分类、时间粒度与样本条件。[国家统计局第三次全国时间利用调查](https://www.stats.gov.cn/zwfwck/sjfb/202410/t20241031_1957217.html)。

一次汇款、迁居或共同陪诊用一个事件 ID，参与者和实际影响分别记录。汇款双方共享交易并按家户口径核销内部流转，陪诊可分段或多人投入但覆盖量只结算一次。承诺、尝试与兑现分别落账。迁居可结束同住区间，而经济供养和关系维持由自己的有时点事件更新。详见[跨学科依据与机制补全](跨学科依据与机制补全.md)和[逐族生成契约](维度体系说明.md)。

### 3.2.3 图版本、LLM 直接修订与依赖重算

LLM 可直接新增、细化、修改、合并或撤销合成节点及关系。编辑接口基于指定父修订创建子分支工作修订，直接应用整组变更，无需人工审批。每次保存 `graph_revision_id`、`parent_revision_id`、`branch_id`、操作、影响范围、模型和校验结果。撤销从子分支的有效图移除事件，并留存理由。拆分和合并保存原节点引用。校验通过后可签发新图版本，保留原快照并按来源许可管理回放访问。

修订触发依赖分析，重算受影响的后续候选事件、状态投影、关系变化与校验结果，在新分支形成新版本。与改动无依赖的前序节点和独立轨迹沿用旧版本引用；同一版本的整笔家庭事件及多人状态增量原子提交。稳定随机流按人物、过程、事件锚点和抽样用途寻址，避免无关新增节点仅因执行顺序变化而重排所有选择。新的问卷调用绑定明确的图版本，已保存的作答仍引用原人物快照。

LLM 可以在新分支修订或撤销缺乏支持的合成节点。普查、法规、研究来源及已登记观察本身不可被覆盖；来源之间冲突时保留各自断言和冲突状态，不能由 LLM 擅自抹去来源。年龄、死亡、时间顺序、关系和共享资源等硬约束由独立校验器检查。校验失败时，LLM 可继续直接修订当前工作分支；尚未消解的冲突保留为冲突状态，不签发为通过校验的版本。

### 3.3 生死状态、静态档案与动态人生

人物至少包含生存状态、出生/死亡日期或区间、记录截止日、模拟模式。

- **已故人物。** 死亡是本人行动、体验和即时作答的终止状态。善后、遗产、身后声誉、家属忆述和档案修订作为其他主体的记录继续存在；如按生前截面做第一人称模拟，明确标识其设定时点和研究性质。
- **尚在人世人物。** 截止日冻结已生成人生及生存观察，未观察到死亡时保存右删失。动态项目从该版继续生成或依新证据在新分支修订，重新验收后发布新版本；旧问卷仍引用原快照。已故档案也可因新增证据产生修订版本，但不生成死亡之后本人的人生事件。
- **未来人生。** 以指定时间线分支生成条件情景，保存介入变量和外部假设、估计依据及适用边界。后续转为新的设定基线时仍保留原分支、生成时间和版本记录。
- **生死或年代不明。** 保留死亡时间区间、状态及证据。以查询时点与区间判断能否提供在世视角，无法判定时输出不确定而非生成一次现时作答。
- **回放。** 固定世界版本、分支和查询时点以重建档案及人物视角，保留此前的模型和实际生成产物。

## 4. 人类构成体系：不以“维度越多越完整”为目标

当前注册表包含 55 族、440 条一级概念记录。每个 `dim_id` 依据语义映射至事件、有效期状态、关系边、规则、观测、人物视角、派生值或作答记录，并用相应方式生成和校验。共有 55 份逐族生成规则涵盖跨族引用、时间精度和缺失。一个概念允许有多个时点实例、不同证据用途或未覆盖值。详见[维度体系说明](维度体系说明.md)和[可版本化的维度字典](维度字典.csv)。

### 4.0 统一解释框架

完整的人物模型不应等于一套人格量表。整合人格研究将稳定倾向、情境化适应、生命叙事和文化/社会处境视为互补解释层；生命周期研究强调人生时点、历史时间、个人能动性与关联生命；行为模型则提示能力、机会、动机和习惯共同影响具体行动。设计据此分开“身体能否做”“环境是否给机会”“本人是否想做”“最终做了什么”，并保留证据状态。

心理构念以测量框架而非本体真理处理：大五、HEXACO、Schwartz 价值理论和中国本土人格研究均可作为候选工具，需对语言、年龄、地区和目标群体验证测量等值。哲学、人类学和叙事理论帮助发现被遗漏的问题与解释视角，但不能直接变成民族/地域标签的条件分布。跨学科依据、阅读层级和可转化机制详见《跨学科依据与机制补全》。

### 4.1 基础层：身体、发展与功能

覆盖遗传/出生环境、身体结构与功能、慢病与急性病、疼痛、感官、睡眠、营养、性与生殖、衰老、残障/功能限制、药物与医疗服务、物理安全。使用 WHO ICF 的思路描述身体功能、活动、参与与环境支持之间的互动；疾病诊断不能单独推出能力、生活质量或社会参与。

覆盖婴幼儿、童年、青春期、成年、照料与老年等发展阶段；发展轨迹需允许个体差异和文化/制度时钟差别。生物年龄、日历年龄、法定年龄和个人感受年龄不可混为一值。

### 4.2 个体心理与行动层

把心理构念拆成可观察行为、测量得分、潜变量假设和模型推断。可考虑人格特质、情绪/情绪调节、认知能力、注意/记忆、风险偏好、动机、目标、习惯、控制感、自我效能、依恋/信任、道德直觉、价值优先次序、信念确信程度、应对策略、创造与审美、灵性/宗教信仰等。

大五人格、HEXACO、Schwartz 价值模型等是可能的测量框架，不是人格完整的本体，也不能把量表分数当作诊断或稳定本质。性格、价值与行为关系取决于文化测量等值、具体情境和时间；应允许量表不适用、题目理解差异及结果不确定。

### 4.3 自我、记忆与叙事层

区分“当年发生了什么”“当年如何体验”“今天如何记得”“今天如何解释当年”。记录自我概念、身份转换、人生目标、重要选择、遗憾、羞耻/骄傲、创伤与复原、人生阶段叙事、隐私边界、秘密和讲述对象。回忆是选择性、重构且会变化的，不应把叙事细节当作录像式史料。

### 4.4 关系与社会生态层

家庭不是单一的亲属表。需要分别表达婚姻/伴侣、亲子、亲属、共同居住、抚养/监护、经济转移、照料、同学同事、组织成员、友谊、邻里、师徒、宗教/文化联结、社区归属和弱关系网络；关系随时间开始、变化、断裂和修复。允许双方记忆不一致、权力不对等、失联和单向支持。

同时建模家庭资源与义务、组织层级、社会资本、身份/角色、社会规范和制裁、阶层流动、歧视与机会结构、社区公共服务。社会结构影响概率与资源，但不能把结构效果机械地归因于个人特质。

### 4.5 制度、资源与生活实践层

教育与培训、职业与劳动关系、收入与财富、负债、住房、户籍/迁移、社保、法律与政治参与、医疗与照料、时间利用、消费、交通、媒介接触、数字设备/能力、文化参与、休闲、饮食、节庆与礼俗、环境暴露、灾害、宗教实践等。把“制度资格”“实际可及”“是否使用”和“本人评价”分开。

### 4.6 地域、民族、语言与文化层

每个文化相关特征至少拆为：法定/统计分类、个人自我认同、家庭/社区认同、语言能力及使用场景、传承经历、仪式/宗教实践、饮食与劳动习惯、跨文化接触、歧视/偏见经历、代际变化。个体可以拥有多个身份、混合家庭和流动身份，也可以不实践某个群体常见习俗。

哲学思想作为解释资源，不作为人口标签：儒家关系伦理、道家变化/处境观、佛教修习与无常、墨家兼爱、法家制度秩序等属于不同历史传统，且内部有争论、地域传播和当代重释。只在有个人教育、文本接触、家庭实践或自我认同依据时，才进入某个人的知识/信仰/实践状态。不得以“汉人/少数民族/某省人”推定其遵循某套哲学。

## 5. 人口数据与来源治理

数据不是用来“证明一个人”，而是限定样本边际、条件分布和联合关系，并为模型覆盖范围提供已知界限。

### 5.1 来源层级

1. **官方普查/抽样调查/统计年鉴：** 人口边际、地区结构、教育、迁移、家庭、劳动等总体和时间基准。保存原始表、脚注、统计时点、城乡/常住/流动定义及修订版本。
2. **长期追踪与专题调查：** CFPS、CHARLS、CGSS、CHFS、CLDS、CEPS、CLHLS、CHNS 等可候选用于家庭、个体、健康、观念、劳动、教育与生命周期关系。每个调查覆盖年龄、地区、波次、抽样设计、问卷语言、权重和公开权限不同，不得仅凭名称推断其代表全部民族或所有地区。
3. **历史与地方材料：** 法律政策原文、地方志、档案、报刊、回忆录、学术史料、民族志和口述史。事件节点要有来源交叉校验，并保留地方/群体差异和争论。
4. **哲学/心理/人类学框架：** 用于组织概念、提出变量与机制，不可冒充人口事实。心理量表必须记录版本、翻译、测量群体、信效度与适用边界。
5. **LLM 生成资料：** 只用于被标记的合成内容、候选事件和语言表达；不能再被当成独立经验数据训练/校准自己，形成循环自证。

### 5.2 每个数据源的登记项

数据源 ID、发布机构/作者、题名、URL/DOI、发布日期、数据波次/统计时点、总体定义、地理与年龄覆盖、抽样设计、分母与有效样本量、变量/题项映射、权重与缺失说明、许可证/获取条件、敏感性、数据质量/限制、最后复核日期。对每条待校准的断言注明精确表号、题号或资料段、转译及适用层级。区分仅见索引、已读发布说明/正文、数据已取得和可以再分发。政策原文确认规则，地方台账可核兑现样本，论文和一手报道可发现机制与例外。各类证据的数字用途依分母、适用时期和识别设计决定。数据更新追加版本并追踪受影响的参数、规则和下游运行。

### 5.3 互补数据源与不可覆盖区域

下列来源是可用的数据拼图，不是能直接合并成全龄、全地区、全民族个体数据库的一套底库。调查之间抽样框、年龄、年份、分类、访问方式和数据开放条件不同；普查汇总表可用于人口边际校准，不等于可取得的个体微观资料。

| 来源 | 可支持内容 | 需要显式保留的缺口 |
|---|---|---|
| CFPS（北京大学） | 个体/家庭/社区多层纵向关系，覆盖多年龄段家庭 | 技术说明所列抽样框不含港澳台及若干边远省区；不等于所有地区覆盖 |
| CHARLS（北京大学） | 中老年、健康、家庭支持、劳动/退休和资产轨迹 | 45 岁以上为主；基线排除西藏和机构养老人口，不能外推全龄 |
| CGSS（中国人民大学） | 大陆社会态度、家庭、社区等重复横截面趋势 | 不是同一个人的纵向追踪；小民族/细分群体样本可能稀疏 |
| CHFS（西南财经大学） | 家庭资产负债、收入、消费、金融行为 | 家庭金融重点；数据申请/访问受项目条件约束，非默认无条件下载 |
| CLDS（中山大学） | 劳动力、家庭、社区与就业迁移轨迹 | 以劳动年龄人口为核心，覆盖范围和轮换/追踪设计有限 |
| CEPS（中国人民大学） | 学生、家长、教师、学校教育环境 | 特定学龄/队列和县校样本，不能代表成人总体 |
| CLHLS（北京大学开放研究数据平台） | 老年、长寿及成年子女信息 | 明显偏重老年人及特定省份/年龄；部分文件需登录或申请 |
| 七普民族分卷/汇总表 | 行政民族分类的年龄、性别、教育、迁移等交叉汇总 | 汇总表不是可直接取得的人级记录；普查不等于语言使用和文化实践调查 |
| 教育部/国家民委语言资源调查 | 少数民族语言资源与选点记录 | 调查点/录音资源不等于全国语言使用率的概率样本 |
| 香港人口普查 | 香港本地族裔、出生地、家居语言与语言能力 | 香港分类和本地人口定义不等于大陆民族分类 |
| 澳门人口普查 | 澳门族裔、常用语言、国籍/居民和人口结构 | 需区分本地人口、非居民雇员、学生及普查年份；分类不宜直接映射大陆 |
| 台湾人口及住宅普查 | 居住、家庭与语言使用相关指标 | 行政分类和统计体系独立；普查语言问项不等于具体原住民族族别覆盖 |

这些调查互补，但任何一次融合都需版本化映射，保留“源字段、目标字段、转换损失、权重、时点、地区和群体有效样本量”。民族、方言、宗教和自我认同不可在不同统计制度之间做无损假设映射。数据源 URL、项目介绍、具体抽样缺口及本轮核查状态见《数据来源与覆盖矩阵》。

### 5.4 当前可确认的基准

截至本文基准日，国家统计局发布的 2025 年全国 1% 人口抽样调查以 2025-11-01 零时为标准时点，样本约 2052 万人，占公布总体约 1.46%；公布人口、家庭、年龄、教育、城乡、流动等指标。该公报的“全国人口”口径是大陆 31 个省区市和现役军人，不包括在大陆居住的港澳台居民和外籍人员。因此它适合作为大陆人口新基线，但不能单独满足“所有地区”的范围承诺。

第七次人口普查公报的“全国总人口”汇总包含大陆 31 个省区市、香港、澳门、台湾相关人口数；组成数据有不同主管来源和统计时点。不得将该汇总值与大陆人口普查分项或年末常住人口直接混用。2025 年 1% 调查时点、2025 年末统计公报时点也不是同一口径。

国家统计局第三次全国时间利用调查覆盖大陆 31 省区市和新疆生产建设兵团，样本约 3.85 万户、10.7 万名 6 岁及以上居民，首次覆盖 6–14 岁并采用两天活动日记；适合校准时间利用的若干总体/分组模式，不代表一个人的完整终身时间账本。

CHARLS 官方项目介绍显示，其总体为 45 岁及以上人群，2011 全国基线覆盖抽取的 150 个县区、450 个村居，并包含个人、家庭、健康、医疗、工作、退休、养老金、收入消费资产和社区信息及后续追踪波次；适用于其覆盖人群和问卷口径，不可外推到儿童青年或作为全民族样本框。

### 5.5 覆盖矩阵，而非一个“代表性”标签

每个字段至少记录按以下切分的样本量/有效率/误差或“不可评估”：地区层级、民族分类、年龄队列、性别/性别认同（按来源实际项）、城乡与户籍、教育、收入/阶层、语言、残障/健康、宗教、迁移/侨居、家庭结构。小群体可过度抽样供机制检验，但汇总统计需按目标总体还原；没有真实基准时，不宣称该群体仿真准确。

### 5.6 从统计表到生成参数

| 待生成内容 | 合格证据 | 必做校验 |
|---|---|---|
| 参照时点的人口与家户结构 | 同框统计及同口径交叉表 | 同时对人、家户和住处核验。各个边际都匹配时仍可有多个不同的联合分布，需留出交叉表并比较至少两组可行关联假设。 |
| 跨期事件与持续时间 | 有风险集和失访定义的纵向跟踪、制度登记、可复核的专题估计 | 分开失访、迁移、死亡、进入和退出样本。两期横截面的人数差不能单独识别某人的改变。 |
| 死亡风险、死因与删失 | 同地区、年龄、时期和适用人群的死亡资料、生命表或经说明的投影 | 区分中心死亡率 `m_x`、死亡强度和区间死亡概率 `q_x`。跨地后按实际居住区间重选风险；灾害已计入基线时，另加超额风险须有可核的扣除依据。 |
| 稀有组合与身份更替 | 同框交叉信息、地方资料、有关人口分类或登记更新的原始来源 | 将结构不可能、抑制、抽样为零、未测及稀疏分别编码。固定统计分类版本与有效期，允许自认、法律身份及登记之间存在时间差。 |

年龄、历史时期和出生队列存在恒等关系。分别用年龄标定风险集、时期索引制度、出生队列定位共享历史条件；若分析要拆出三者各自的效应，需明确可识别约束或中介及其证据，并报告替代设定。详见[人口与生存资料](数据来源与覆盖矩阵.md)及 [Winship 与 Harding 的识别研究](https://cwinship.scholars.harvard.edu/sites/g/files/omnuum1506/files/cwinship/files/apc_08.pdf)。

## 6. 历史节点：从年表升级为“暴露—机制—分化”知识网

系统应维护版本化的历史节点目录。单纯“某年发生事件”不足以生成可信人生。节点最少含：节点 ID、事件名、起止或不确定日期、地理范围、受影响人群、制度、暴露渠道、作用机制、机会/约束变化、证据来源、地区差异、争议/反证、影响延迟、可能反应路径、受影响维度、置信程度和版本。

### 6.1 四层历史知识

- **宏观背景：** 政权、经济体制、人口政策、产业/教育/医疗/住房/劳动/社保制度、技术基础设施与重大公共事件。
- **地方机制：** 省、市、县、乡镇、社区的执行差异，产业、语言和文化场景，城乡/边疆/海岛/城市化差异。
- **个体暴露：** 是否亲历、何时接触、渠道（家庭、学校、工作、新闻、社交网络）、暴露强度与持续时间。
- **个体反应：** 受资源、健康、关系、信念和偶然性影响的多种选择与结果；包含不受影响、受益、受损、抵抗、回避、误解等不同路径。

### 6.2 历史节点候选目录

以下为目录骨架，不是完整历史，也不规定所有人都受到同样影响。每条落库前需关联适用地域、来源和机制；对重大灾害、政治运动、饥荒、疫情等尤其不能由出生队列直接断言个人创伤或立场。

当前版登记 69 个历史节点及 69 条逐节点推演规则，涵盖中国大陆、香港、澳门、台湾及部分侨居地。每条有时间窗、地理和资格范围、暴露渠道、关联维度及来源边界。本节表格用于规划年代与主题覆盖，具体节点以[历史节点与环境暴露目录](历史节点与环境暴露目录.md)为准。

| 时期/节点 | 影响机制候选 | 需要防止的简化 |
|---|---|---|
| 近代战争、政权更替、土地与社会制度变动 | 家庭迁徙、财产/职业变化、教育和代际记忆 | 将全国不同地域、民族和家庭写成同一种经历 |
| 1949 后土地、婚姻、教育、单位与基层制度重构 | 财产与家庭关系、劳动/组织身份、公共服务和生活规范 | 把法律颁布等同于每地同日同效实施 |
| 1950 婚姻法及后续婚姻制度变化 | 婚姻自主、家庭结构、性别关系、登记与风俗并存 | 仅用现行婚龄门槛校验历史婚姻 |
| 1958 户籍制度形成及后续改革 | 教育、就业、福利、迁移成本与城乡机会 | 把户籍身份等同实际居住、阶层或个人态度 |
| 1959–1961 等重大困难时期 | 营养、健康、迁徙、家庭策略与长期记忆 | 从出生年份/籍贯自动推断个体受灾、饥饿或创伤 |
| 1966–1976 社会与教育秩序剧烈变化 | 教育中断/替代路径、家庭分离、工作分配和代际记忆 | 把宏观标签直接写进个人政治态度或创伤 |
| 1977 恢复高考、1978 改革开放及地方开放/产业变迁 | 教育与职业通道、人口流动、收入和消费机会 | 假设所有省份、行业和家庭获益相同 |
| 1980 年代至 1990 年代就业、企业与人口流动变化 | 单位制变化、农民工/个体经营、社会保障连续性 | 把就业轨迹压缩成单一“下岗/南下”模板 |
| 1998 城镇住房制度改革 | 福利分房向货币化/住房市场转换，家庭资产/负债关系改变 | 断言全国每地同时终止福利分房 |
| 2001 WTO 加入及数字/制造业扩张 | 地方产业链、岗位、迁移和消费环境变化 | 用宏观增长推断个体职业必然上升 |
| 2003 SARS、2008 汶川地震与金融危机 | 公共卫生、灾后重建、家庭风险与行业冲击 | 将新闻接触视为亲历或同一种心理后果 |
| 2010 年代智能手机/移动互联网扩散 | 信息接触、支付、社交、数字排斥与平台劳动 | 默认年龄、民族、城乡足以推出数字能力 |
| 生育政策阶段性变化 | 生育机会、罚款/服务、家庭规划与地区执行差异 | 用现行政策倒推历史合法性和实际选择 |
| 2020 起 COVID-19 与地方防控差异 | 健康、照料、就业、教育、流动和信任的多路径影响 | 把全国性节点等同统一暴露、态度或创伤 |
| 2024 起渐进式延迟法定退休年龄改革 | 年龄、性别、岗位类别、缴费年限和个人弹性选择 | 用一个固定年龄描述未来退休路径 |
| 2025 人口抽样调查与后续社会趋势 | 新人口结构基准、老龄化、家庭规模、流动和教育变化 | 将调查时点值与年末值、不同总体混用 |

时间轴要允许按主题展开：家庭/亲密关系、教育、职业、迁移、社会保障、医疗、住房、技术、环境和群体历史。对于各民族历史、地方制度、跨境与港澳台经验，应通过专项可信来源持续扩充，不以一条“全国大事记”替代。

### 6.3 跨时代知识覆盖骨架

历史节点库的研究范围不能从1949年才开始。每个时期要先明确可用资料的类型、可支持的细节精度和不确定性，再决定能否用于生成人物。以下是资料建设的时间覆盖提纲，不是已经完成的事件目录，也不表示该时期可可靠生成人口级个体：

- **史前与早期文明：** 考古遗址、古环境、物质文化、定居和生业变化；人物层只能在合格史料/考古模型支持的范围内做明确标注的情景模拟。
- **早期国家与经典形成时期：** 政治组织、社会身份、礼制与法律、书写/教育、区域交换、思想传统及其后世解释；避免把典籍中的规范直接投射成普通人的实际生活。
- **帝国时期与历代政权更迭：** 官僚与地方治理、土地/赋役、教育选拔、军役、宗族与家户、城市和市场、交通贸易、战争灾害、边疆交往、人口迁移及地方社会差异；节点需注明史料类型、地理尺度和不确定年代。
- **晚期帝制向近代转型：** 手工业/商业、内外贸易、区域经济、人口流动、宗教网络、条约/战争、改革与教育变化；不把沿海城市史自动外推至内陆或边疆。
- **民国及战乱、政权与制度变迁时期：** 学校/职业/土地、户籍/法律、军事动员、迁难与流亡、地方政权、语言教育、家庭生计；个人经历常受地点、阶层、民族和档案存留偏差影响。
- **1949年至今：** 继续按上文政策、产业、教育、公共卫生、住房、人口流动、社会保障与技术分期记录，并纳入各省区、市县和群体的不同执行、机会和结果。

跨时代人物的代际记忆要由可追溯的口述/文本来源产生。史料中的人物、制度和统计不等于对全部普通人经验的观察；需要区分“能够从史料知道某制度存在”和“某人物当时接触并体验了该制度”。历史来源登记、争议解释和多版本注记由《历史节点与环境暴露目录》、《跨学科依据与机制补全》和《数据来源与覆盖矩阵》继续细化。

### 6.4 环境约束 C：可查询的时空机会结构

`C` 不是一个可乘进人生公式的分数，也不只是出生地加时代标签。它是随时间版本化的外部状态向量与关系图，至少分为七类：

1. **自然地理与区位：** 生境/气候/海拔/水文/地质风险、地形阻隔、交通可达性、土地与资源条件；行政区划必须使用当时版本。
2. **制度与政策：** 法律/政策有效时间、地区实施时间、适用身份/资格、公共服务规则、单位和学校制度、救助与社保资格。
3. **地方经济与劳动市场：** 行业/国企与民营结构、岗位和工资、产业衰退/扩张、迁移目的地、季节性劳动、就业服务与培训。
4. **教育、医疗和照护供给：** 学校距离与招生、语言/无障碍支持、诊疗和保险可及性、照料网络、托育/养老服务。
5. **基础设施与技术：** 住房与建筑质量、道路/铁路/航运、供水供电通信、互联网/终端可用性、市场与物流，记录建设和停摆时间。
6. **灾害和环境暴露：** 官方危险区/烈度/洪水范围、受灾时段、房屋/生产/服务损失、预警/转移/救援/重建、污染和极端天气；允许多灾种叠加。
7. **信息、关系与社会网络：** 家庭成员远近、单位/学校/社区、媒体与通信渠道、迁移网络、互助/冲突和救援来源。人物可能因家庭成员在异地而间接受影响。

按人查询的 `C_person(t)` 至少关联出生/居住/工作/上学/就医地点和有效时间，家庭/关系暴露、身份/资格、到达与离开、通勤/迁移、服务使用、风险强度和信息渠道。某节点只有在地理/时间匹配且存在相应渠道时，才进入个人候选经历；“接触机会”还要和“实际接触、理解、采信、记忆、行动”分开。

先用 `C_world(t, place)` 取历史地理和当期规则，再连个人活动地点、资格、关系、单位、能力、时间与资源，形成该人当期的机会与暴露。政策记录法定适用、地方展开及现实供给、本人或代理获知、意愿与权限、申请/审核、履行/到账及后效。公布后尚未实施的事项可改变预期；追溯计补可以覆盖此前月份，实际到账仍只进入当时现金账。灾害另区分在场、家庭网络、服务中断和仅获知；节点叠加时共享损失账本。允许无直接影响、未接触、申请失败、暂不行动、受益与受损并存及延迟恢复。每条状态增量保存来源、候选分支及校验版本。

空间分辨率按来源能力递减：官方灾害烈度图/政策文本支持到乡镇或县时才使用相应粒度；只有省级汇总就不伪造县级乃至街道级暴露。缺少个人定位证据时，存为 `unknown` 或“潜在影响”，不可由 LLM 填补。环境资料与个人事实必须分库/分层管理，来源修订生成新版本并重跑受影响人物和验收。

统一的历史情景案例包含 26 个主题案例和 2 条跨节点履历，涵盖灾害、产业、教育、福利、迁移、基础设施和跨境政策。汶川地震、东北国企下岗与其余案例使用同一组判定事项。完整字段约定与逐节点校验规则见[历史暴露推演与个人路径机制规范](历史暴露推演与个人路径机制规范_v1.md)。

## 7. 人生生成流程：约束前置，候选推进，账本验收

LLM 在本系统中承担五种可切换责任：规格整理和工具编排、骨架提议与编辑、细节和叙事填充、独立审查修复协助、人物视角问答。每种责任使用类型化输入输出、角色标识、版本化配置和任务权限，工作流负责阶段状态，领域工具负责数据和约束。任务和接口细化见 [LLM 人生生成与数字人问答设计](LLM人生生成与数字人问答设计.md)。

程序抽样及来源检索提供总体、世界与初始状态。LLM 在当前工作分支直接建立或修订时间事件图，生成符合处境的可能事件、节点细节和人物表达。每次修订触发依赖后继重算并创建保留旧版的新分支。独立校验器检查结构、来源与状态变更。若支撑机制只有个案或定性证据，事件保留机制/情景标签和概率未知。

### 7.1 建议的生成顺序

1. **选择总体与抽样入口。** 锁定人口框架、出生队列、分类版本、截止日及用途。只有选定的抽样框才决定是否以存活或死亡为预置条件。从出生模拟时抽样死亡于推进过程中完成。
2. **抽样个人与关联生命。** 用有证据的联合分布同步建立个人、家户、住处、照料和核心关系。保留可检查的稀有组合、附带 person ID 的次要人物，以及待验证的弱证据。
3. **建立时空机会结构。** 以当前时期、实际活动地点、关系、资格、资源和能力查询制度及历史节点，维护普通生活节律、现实暴露和人实际能见的选项。
4. **建立或修订事件图。** 针对当前状态建立风险集、候选与等待条件，显式保留维持现状、未行动和失败。LLM 可在子分支工作修订中直接添加、拆分、修改、合并或撤销合成节点与关系。
5. **推进最早会改变状态的事实。** 核对约束、冲突、相互依存和终止事件；写入同一账本，对所有受影响参与者计算状态增量并重算后续候选。含不确定时序的记录保留区间，不能通过模型另写无证据具体日期来消解排序。
6. **推进认知、记忆与叙事。** 从人物可得信息和已发生的经历形成当时信念，以后允许回忆减弱、偏移或重释。同一状态可以生成多种措辞，逐字对白和感官修饰属于合成叙述。
7. **沿依赖重算并校验。** 计算本次修改影响的后继节点闭包，重算候选、状态、资源和多人物关联事件。按结构、历史、家庭、资源、认知、文化/语言和权限分别校验；保留修复、未决冲突和失败记录，检查重算是否改变总体分布。
8. **保存新分支版本。** 新版本记录父快照、修改节点、依赖重算范围、模型/提示/参数版本、随机状态和验收结果。保留旧版供回放；发布时冻结该版供问卷批次使用，后续续写从新分支开始。

### 7.1.1 并行轨迹、竞争事件与推进

初始状态包括尚未结束的轨迹、参与者、常态计划及资源。给定此状态，失业和主动换岗可以竞争成为某份工作结束的第一个原因；失业后的新工作仍是下一状态的可选转移。健康变化可能不终止学业，但会改变出勤和照料需求。一次检测结果可发现在先的疾病并晚于真实病程。发生竞争事件后重算风险集与区间，允许长期无变化、事件复发或延迟兑现。死亡终止本人行动并取消未兑现的个人计划，其他主体的照料、遗产和回忆继续依权限入账。用相同观察窗口比较事件年龄、累计发生率和状态停留时长。该项目借用竞争风险和多状态分析的结构，具体转移率需用适用调查、登记或研究重新估计。[Putter、Fiocco 与 Geskus 的多状态分析原文](https://www.est.ufmg.br/~enricoc/pdf/sobre/Putter2007.pdf)。

例：人物原定六月赴外地上岗，五月家长出院后连续六周需要有人在场陪诊。地点、交通和排班使两项起初冲突。候选包括乙分担陪诊、购买真实可及的服务、入职延期、尝试未获批准以及部分照料落空。成功分担以共同陪诊事件记在两人账本；未落实的照料不把亲属角色改写成已服务。六月仍实际赴岗时才开始外地劳动区间；后续依据本人是否知道原来的不确定安排，决定问卷中如何讲述。该例可直接检查常态约束如何改变人生路径，无须引入宏观冲击来解释转折。详见[关联生命的多分支示例](跨学科依据与机制补全.md)。

### 7.1.2 生成作业断点与血肉填充

生成作业保存状态机：

```text
request_received → spec_ready → skeleton_running → skeleton_review
  → flesh_running → chain_review → repair_loop → publish_pending → ready
```

失败、取消、待用户输入或预算耗尽也要保存为有原因的作业状态。工具重试引用原任务和幂等键。**骨架审阅**显示可读快照、结构和时序错误、证据不确定、覆盖范围、可能影响的关联人物和本版差异。用户可手动编辑、用自然语言指示 LLM 直接修改或回滚草稿。LLM 编辑仍写成图的子分支工作修订并进行重算和自动约束检查。用户点击继续时，作业固定已选定的 `graph_revision_id`，以该版本作为后续血肉生成的唯一结构输入；刷新和重复操作不得偷偷换版。

后续 LLM 依生命周期区间和事件依赖分块生成经历细节、记忆、动机、表达特点与叙事材料。每个内容块记录 `detail_revision_id`、锚定 `event_id`、依赖图修订、模块/主题、内容模型和提示版本、证据来源、生成与校验状态以及实际文本。如果扩写产生新的实质经历，进入图修订和重算流程，不能只加叙事绕过骨架。如果修订图，已生成且依赖受影响节点的块将失效并重新扩写；无关块沿用既有引用。细节可按覆盖、重要性、回答用途和证据强度逐层生成，避免将缺乏依据的内容写成确定事实。

### 7.2 LLM 输出与事实边界

生成规格、人口工具调用、运行器、LLM 产物及审查报告都按调用职责记录到 `run_id`，不能将下列来源混在同一种“事实”中：外部来源断言、合成世界的采用事件、等待决定的候选、人物当前状态或记忆、可读叙事及问答回答。工具只暴露当前角色被允许的能力。图编辑器、细节填充器、独立审查器和问答生成器使用不同的任务目标和发布权限。具体阶段、产物和检查见《LLM 人生生成与数字人问答设计》。

LLM 对当前工作分支的直接写入按下列语义分类：

- **硬约束字段：** 需满足人口/制度/数学规则；例如年龄顺序、时间区间、亲属生育关系、财务约束和政策有效期。
- **概率性个体路径：** 允许合成，但须受人口联合分布和历史机制校准。单个合法故事仍不能证明概率合理。
- **主观构念：** 允许有依据的个体差异，但需附时间、形成机制和推断不确定性，不能从标签模板直接复制。
- **叙事装饰：** 气味、光线、逐字对话等可用于可读性，但属于合成叙事；不得将其作为研究证据或事实检索结果。
- **未来情景：** 需声明情景假设、模型版本和随机性；不得与历史档案合并。

允许的图操作包括新增节点、拆分粗节点、修改合成内容、合并同一经历的重复节点、撤销合成节点和更新不同类型的关系边。直接写入不代表跳过校验或抹除 lineage。改动后必须重算受影响依赖并生成子版本。素材无法支持唯一修正时保留冲突断言，不以故事连贯性作为证据。

单一 LLM 不能同时作为生成者、权威事实源和唯一验收员。验证需要独立程序规则、资料检索、独立评测模型/人类专家抽查及留出的真实数据基准。

### 7.3 路径模板定位

模板可保留为生成策略和覆盖检查用的“常见轨迹原型”，不能成为人物类别。模板应拆成可组合的机制模块（家庭资源、教育机会、地区产业、迁移网络、疾病冲击等）；人物可跨模块、偏离基线，并能产生罕见但可能的路径。生成时先抽初始条件和环境，再让路径从机制中发展，避免先判“农民工/白领/少数民族”再把整生写成类型故事。

## 8. 动态人生与反事实运行

对活体人物的后续发展，运行时必须包含：当前状态快照、有效关系网、个人知识截止时间、外部环境/政策版本、事件提议、行动选择、关系影响、状态投影、验证与新版本归档。

未来发展不是无条件续写传记。运行时提供：

- **继续：** 从当前状态与给定未来外部条件继续生成。
- **情景：** 针对指定变化（换城市、失业、照护、政策变化等）开展分支情景。
- **反事实：** 明确改变一个或多个条件，复制时间线而不污染基线。
- **冻结：** 冻结版本，用于可重复的问卷批次/AB对比。

修订以 `branch_id`、`graph_revision_id` 与 `parent_revision_id` 保存主父链，合并修订另记合并来源。条件情景及反事实额外引用 `scenario_id`，锁定比较基准、规则、干预时点和假设。每次图写入保存实际产物和运行清单，按操作幂等键去重。共享事件及其各方增量同版提交，发布固定 `release_id`，已存作答保留当时的 `snapshot_id`。反事实描述指定模型和假设下的结果，现实因果效应需要独立识别设计。

## 9. 面向下游 Agent 的问卷受访者契约

### 9.1 请求上下文

每次请求锁定会话、题目与量表版本、原文及选项顺序、测量目的、语言或协助条件、被询问的人与实际说话者、作答时点及题目参照期、情景及人物快照、渠道、在场对象及追问规则。服务端根据调用方权限、会话角色与用途派生实际可见范围。代答时读取代答者在作答时能知道的内容，避免把被询问者的私下经历或全部档案投给代答者。

### 9.2 人物如何作答

1. 校验生存状态、年龄、本人或代答资格及路由条件，区分未呈现、跳题和未完成。
2. 确定所问的是事实、回忆、态度、意愿、行为还是知识。核对「本人收入/家庭收入」「户籍地/常住地」等统计单位，允许按规则澄清。
3. 用作答时快照查询人物能回忆、表达且可披露的信息，再按参照期筛选。题目问过去时，仍使用人物在答题当时的回忆反映过去。由人口队列推断的典型态度不能作为个人答案。
4. 用会话条件映射到合法选项、区间或文字。分别保存未知事实、没听说、记不清、未形成见解、知而拒答、暂停及系统错误。已有证据支持的跨题差异可以保留。
5. 将答复追加到会话观察，附权限内可定位的证据与运行版本。题目假设、回答和模型润色均不重写人生账本。单独授权的研究情境可另建参与问卷的事件。

### 9.4 下游检索与回查

| 检索视图 | 返回对象与引用 |
|---|---|
| L0 身份卡 | 人物版本、查询时点、许可范围内的身份与关系导航指针。外链指向关联实体时要重新鉴权。 |
| L1 族摘要 | 指定时点的状态与少数时间线锚点，保留未知、区间和证据用途。摘要使用已过滤的账本投影。 |
| L2 族详情与时间线 | 可访问的有效期、原子事件、观察和依赖引用。字段及时间索引采用同一快照参数。 |
| L3 叙事与引文 | 可访问的记忆、自述和引用片段，附当事人、回忆时间、事实锚点、版本与合成状态。语义相关度只决定候选顺序。 |

检索工具先限定授权对象、图修订、查询时点与用途，再按字段、时间或文本查找。跨人关系每次查阅重新鉴权。报告保存调用参数、证据引用、会话版本和结果码。核对引用的主体、时间、状态及口径。证据精度不足时返回支持的区间或未知。L0–L3 是检索层级，第 10 节 V0–V4 为验收标识。

### 9.5 自由问答中的数字人代理

自由问答复用相同人物视角和权限检索，轮次绑定发布、图修订、snapshot、时间视角、调用者范围和对话会话。回答模型可用第一人称表达该档案中的人物，但这是受证据约束的角色模拟接口，并不表示模型持有本人的意识或真实私人记忆。每项事实主张要有该视角可见的引用。证据支持的记忆与外部核实事件分开，允许可靠表达人物的犹豫、误记、矛盾、无意见和拒答。不支持的细节不根据模型先验补写。聊天消息和回答不能自动写入 LifeGraph。只有用户明确请求档案更正，才另行启动有版本、重算和验收的编辑流程。

## 10. 可信度和验收：四种不同的“像真”

禁止只用“硬矛盾=0”“LLM 看起来合理”或几个样例回答作为通过条件。所有验收报告明确总体、地区/人群、问卷/事件主题、数据时点、基准样本和不确定性。

### A. 规则与档案一致性

- 日期、年龄、事件顺序、婚姻/教育/职业等状态机、亲子关系/多代关系、收支资产/负债、死亡后的事件边界、未来/历史区分。
- 不是单一固定婚龄/退休年龄：规则支持法律时期、地域、身份与实际行为差异；违法、非正式、未登记和违规经历可作为真实发生的事实记录，而不是一律拒绝写入。
- 历史制度/技术/产品与时间、地理可用性核验；宏观节点是否被个人接触独立验证。
- 人物自述、不同关系视角、叙事素材与结构化事件冲突时标记差异，不隐式覆盖。
- 验证多人的同一交易只结算一次，资源、时间和空间均可对账。来源权限不足或跨分支时不得查出间接泄漏。以同一输入重跑需要保留证据标识和既有会话。

### B. 人口统计和联合分布

- 边际分布：年龄、性别/来源性别项、地区/城乡、教育、家庭、就业、迁移等与目标统计相符。
- 联合关系：出生队列×城乡×性别×教育×民族×地区、家庭成员结构、代际资源、迁移来源/目的地。
- 评测指标可包括加权边际差、最大标准化差异、总变差距离、相关矩阵差、联合格点稀疏度及置信区间；稀疏小群体优先报告不可评估/高不确定性，而不依靠平滑后夸大通过。
- 在不同合成规模上检查配额误差、尾部覆盖和随机种子波动；小试点只验证机制，不宣称全国代表性。

### C. 人生轨迹和机制证据

- 与真实追踪调查比较生命阶段转移和持续时间，而非只核对终点标签：教育、初次就业、迁移、婚育、离职/退休、健康变化、照料和居住。
- 检查不同群体间的条件关系、事件序列、转移率和生存曲线；由独立数据/年份/地区留出验证，避免把生成数据源样本泄漏成“外部验证”。
- 做负控和对照：无相关通道的人不写入该节点归因；接受同一政策的人因知情、供给、关系和行动时点出现不同路径。移除作用渠道后的变化与机制预设比对，影响大小和方向依识别假设或资料；预测成功及模型反事实本身均不能建立真实的因果效应。
- 专家和目标群体审查不常见/边缘路径；“罕见”不等同于“错误”，“符合典型”也不等同于“真实”。

### D. 问卷和行为效度

- 对有真实微观基准的题目，用同一调查样本框、同一问卷版本、同一时间点/背景做预注册的盲测；按题型、总体、群体和模型分别比较。
- 同时报告答案类别概率、边际与联合分布、组间差异/排序、与关键协变量的关系、跨题一致性、重测稳定性、开放题主题与表达质量；使用置信区间和多模型/多次抽样。
- 严格留出真实问卷、波次、题目或地区测试外推能力；不把训练/调参所用题目上的拟合称为一般性能力。
- 每次模型/系统提示、维度词典、历史库或抽样校准更新后，跑基准回归；建立误差切片，优先检查民族/地域小群体、老年人、低教育、农村、残障和少数语言人群。
- 公开历史题区分项目留出和基础模型潜在见过；以前瞻封存的真人独立波次或新题降低污染风险。对照相同人物仅有标签、逐步加事实、加视角记忆与加叙事的版本，并与同口径统计基线和真人重测比较。报告合成方差、拒答、跨语言、模式和渠道的变化。

### 10.1 可分级验收

| 等级 | 可声明内容 | 最低证据 |
|---|---|---|
| V0 结构 | 能生成、查询和回放 | 模式、状态投影、引用与权限边界检查 |
| V1 逻辑 | 硬规则通过 | 自动规则、分层抽检及错误诊断 |
| V2 总体 | 指定总体边际及相关联合分布接近基准 | 加权指标、误差区间、覆盖矩阵 |
| V3 轨迹 | 指定领域的过程及机制符合验收范围 | 留出纵向数据与跨地区或队列复验 |
| V4 指定问卷任务 | 指定题组、总体与施测条件满足用途 | 独立真实样本、预注册阈值、复现与漂移监控 |

每个发布用途按人群、题型、时期和证据范围登记适用的验收项。

### 10.2 整条管线的反例

| 回归输入 | 可核验的预期结果 |
|---|---|
| 出生只知年份，事件发生在同年生日可能跨过的时段 | 年龄输出保留合理区间。法定资格无法判断时保留未知，计算规则记录使用的何时何地口径。 |
| 领取一笔可追溯补贴，受理和拨款晚于覆盖月份 | 核算期和到账期单独存在，作答时是否知道以渠道及时间判断，事后补录不会让早期回答出现这笔收入。 |
| 同一祖母被安排同一小时在两座城市陪诊，或两份账本重复结算一笔汇款 | 活动冲突被阻止或改期，资金流和共享事件标识唯一。正常并行的次活动保留。 |
| 已知当时发生迁居，人物记错年份，后来才补档，第三人无权访问 | 事实投影、当时所知、后来的回忆和第三人请求分别返回相应结果。旧会话答案、回忆误差及补档历史可复查。 |
| 分别以出生和参照日存活为入口生成相同出生队列，再在出生模拟中发生早逝 | 两种统计使用各自分母。死亡停止本人后续事件和即时回答；可检索有权限的家属解释或同一时期的生前回放。 |
| 用地域、民族与出生年份查询婚育价值观，履历无直接依据 | 人物快照证据不能由群体标签补写；开放题可表达缺少观点，量表用合法状态。群体统计仅在聚合或公开的抽样参数里出现。 |
| 不同伴侣协商机制都满足人口边际，但产生差异较大的育儿分工 | 两种假设分别报告独立联合/纵向检验和敏感性，边际拟合不抵消薄弱的机制证据。 |

## 11. 主要风险与治理

- **典型化/刻板化：** 以民族、地域或阶层标签自动生成语言、婚育观、政治态度或职业命运。治理：属性解耦、非典型路径、群体切片审计、目标群体审阅和不确定表达。
- **模型主流偏见：** LLM 训练语料对年轻、城市、受教育高、上网活跃人群过度表达，导致边缘经验缺失。治理：真实样本切片评测、开放题与量表分开验证、来源与不确定性显式化。
- **宏观事件个人化：** 根据出生年就生成灾害、运动、创伤或政治态度。治理：显式建暴露渠道和个体证据，不让历史节点直接覆盖人物状态。
- **伪精确：** 合成精确金额、生日、细致病史和感官记忆给人以史料确定感。治理：区间/模糊时间、证据等级和虚构叙事标签。
- **量表实在论：** 把一种人格/价值量表变成人类全部心理。治理：多框架、可选题项、测量等值测试、拒绝推断和自陈误差模型。
- **群体统计替代个人事实：** 分布匹配无法告诉某个合成个体真实会如何作答。治理：把个体差异视为模型样本，不声称精准复制现实个人。
- **调查污染/误用：** 合成答复冒充真实受访者、混入真实问卷，或被用于影响舆论和决策。治理：机器可读合成标签、批次追踪、下游使用说明，不做反机器人规避。
- **数据泄露与重识别：** 真实调查微观数据可能含敏感属性，即使发布为合成记录也有记忆/成员推断风险。治理：仅在许可条件下使用、最小化敏感字段、做成员推断/近似记录风险测试，优先生成而非复制稀有真实记录。
- **系统自证循环：** 合成人物的回答反过来被加入训练集或校准集。治理：数据来源链和训练排除标记，任何合成样本不得伪装为现实观察。
- **时间和政策漂移：** 法规、统计口径和模型不断变化。治理：全部规则/数据有效期版本化；过期规则让验收失败而非静默沿用。

## 12. 从原设计继承与修正

|---|---|---|

| 状态 + 事件 + 环境 | 保留并扩展 | 增加主体/关系/家庭/组织/认知/证据/问卷和时间视角 |

| 只由程序生成硬骨架 | 改为混合生成 | LLM 可生成完整人生候选，由统计数据、制度历史、事件约束和独立评测共同把关 |
| LLM 只填血肉 | 改为版本化的图生成与直接修订 | LLM 可直接更新活动分支的合成节点；修订沿依赖重算后继并形成新版本。来源记录保留、硬约束校验独立运行，旧版可回放 |

| L0–L3 分层检索 | 保留并补充 | 绑定访问控制、人物时间快照、证据状态、来源和问卷版本 |
| 硬/软一致性 | 扩为四类效度 | 规则、分布、机制、行为/问卷效度分开验收 |
| 已故/未故生命周期 | 补为一等概念 | 死亡终止本人行动与实时作答；在世人物可在截止日后续展；未来和反事实有独立分支。 |
| 200 人按省配额试点 | 不足以验证所有群体与统计效度 | 可验证管线与边界案例；人口效度用大规模/独立分组样本及区间验证，小群体需专项过采样 |
| 轨迹回查答案事实 | 保留并增强 | 回查人物快照、问卷时间、答复证据和题目上下文；不能只检查字面命中 |

## 13. 建议的研究与验证节奏

### 阶段 A：定义基线与口径

完成总体定义、维度字典、事件 schema、证据状态、地理/民族口径和来源登记。先消除族数、维度数、人口范围和年份口径歧义。

### 阶段 B：构建黄金基准

从有许可的公开/研究调查中选少量高价值领域（家庭人口、教育、迁移、职业、健康/老年、价值/问卷）建立训练、校准、留出集；固定问卷版本、统计口径和基线模型。对数据敏感字段先做合规与隐私评估。

### 阶段 C：小批量多群体生成

设计两类试点：保留抽样概率和权重的总体样本，以及覆盖弱证据群体和复杂路径的机制样本。由可用真人样本、目标误差与切片确定所需规模。逐人保留生成审计、验证失败记录与分支元数据，避免为了减少错误而选择性丢弃困难人物。

### 阶段 D：独立评测后再扩大

按 V0–V4 验收项和用途逐项报告。模型、政策日历、历史库和源数据更新后执行回归及漂移测试。把失败的题目类型、群体切片和人生机制记录为版本化误差账本。

## 14. 本版明确未解决的问题

这些问题不阻止形成设计基线，但会影响实际可用范围，后续应按优先级研究：

1. 海外华人纳入哪些国籍、侨居代际和统计总体；香港/澳门/台湾使用何种可比层级。
2. 各少数民族和地区的公开微观数据/可许可数据覆盖如何；是否需要目标群体访谈补充，以及样本规模如何披露。
3. 问卷首次外部验证的总体和领域、独立真人样本与误差限待确定。人格、消费、公共政策、健康等主题的适用范围从等价测试分别取得。
4. 人物所用心理构念哪些需要量表支持，哪些只作为叙事变量；哪些不可从档案中推断。
5. 地方史、民族志、历史法规和政策日历维护的责任主体、审校流程、更新时间和争议处理方式。
6. 真实调查微观数据的许可、研究者访问、模型训练限制和隐私攻击评估如何落实。
7. 性别认同、性取向、宗教、残障、政治身份等字段可在相应维度表示，个别值的收集、生成与披露由用途、数据许可、人物可见性和隐私规则分别约束。
8. 仍需采集或申请各地区和年代的人口联合分布、连续转移、风险和资源轨迹；逐族规则与历史案例目前提供设计级操作和可否证约束。
