# 虚拟中国人维度体系 v3：字典与使用边界

资料复核日期：2026-09-29。本版补充了逐族写入规则、字段级时间与证据用法，以及可直接转为生成测试的案例。本文与同目录 [维度字典 CSV](维度字典.csv) 配套，注册可表达的概念、它们的上下文与验证要求。尚缺直接来源和校准数据的条目可以承载待验证的合成假设；统计输出遵循目标人群、证据和外部验证的适用范围。

## 1. 计数与层级

跨模块标识、图版本和时间字段遵循[全链路设计复核与统一契约 §3](全链路设计复核与统一契约.md#3-统一术语标识和时间)。维度键标识可复用定义，实例通过主体、有效时间、图修订和来源定位。

本版 CSV 为 **55 个族、440 条一级维度记录**，每族 8 条。计数单位是可独立定义、关联与更新的概念记录，**不是 440 个可直接独立抽样的标量**。例如“语言能力谱”需进一步展开成语言×听说读写×时间×情境；“资产可支配性”要区分所有、使用、收益和处置权。条目的组合、拆分与参数数量应由具体研究目标决定，不能用字段越多证明模型越真实。

每条记录的 `dim_id` 唯一且稳定，中文族名可以改；`family_id` 用于跨族关联。`关联维度` 当前是导览用的相关族 ID。复核为 19 个族的 33 条高风险概念补充了条目级时间、来源检索、缺失或禁止推断的规则。其他条目可按第 10–13 节的族级规则及任务需求进一步登记。因果影响只有在来源和目标口径相符时才进入校准参数。

## 2. 什么需要分开

- **世界事实**：某地发生过什么、制度何时对何人有效。人物未必知情，更未必相信。
- **个体事实**：在合成世界内已经确认的人生事件、状态或资源。它仍然是合成设定，不能变成真实受访者履历。
- **主观状态**：人格、价值、感受、信念、欲望和自我叙事。可有犹疑、矛盾、误解、遗忘，不要求全部精确自知。
- **关系**：至少包含两端、方向、有效区间和双方视角。法律关系、共同居住、照料和亲密程度不可互换。
- **观测**：测量、自报、他报、档案或临床记录。记录可错，量表分数不等于诊断。
- **作答**：人物在特定题目、语言、方式、参照期和情境下形成并表达的回答。它不是把内在状态直接抄入选项。
- **元信息**：来源、分类与量表版本、时间、生成依据、修订和不确定性。

CSV 的 `状态层` 是条目主归属，已按具体条目区分，例如出生性别登记属于观测，自我认同属于主观状态；目录中的主状态层仅概括该族。一个结构化条目中若同时存在事实和自述，仍须在展开后分别标注。分类用于防止混淆，不是互斥的存储实现要求。

## 3. 静态、动态与知识边界

已故人物的人生事件止于死亡，之后只能追加**死后记录、遗属事件、史料发现和更正**；不得把死后事情写进本人的生前知识。若要让已故人物在某个历史时点回答，年龄、关系、知识、信念、语言和可见档案都要截到那个时点。死后访谈若采用“回顾式档案叙述”，须明确这是研究者视角，不能冒充本人继续生存。

存活人物的人生只确认到生成截止时点；未来发展是注明场景假设的分支。未来事件尚未发生时，不得用预抽的死亡日期、升迁或家庭结果反向影响今天的回答。新事件应同时作用于资源、关系、身体与认知；身体与心理可恢复、学习和代偿，不能用单向折旧描述所有健康过程。

按需保存实际发生或适用时间 `valid_time`、档案登记时间 `recorded_at` 及每个角色的获知时间 `known_at`。问卷在作答时点取得角色可知及可披露的信息，再按题目的参照期筛选所问经历。后来获知的过去事件可以用于后来的回顾，亲属档案访问与角色知情各自判定。

## 4. 取值、缺失与证据

本 CSV 的值类型是概念级建议，不是已定稿数据库 Schema。数值必须有单位、尺度、时点和误差；分类必须有地区与版本；量表必须说明语言、题项、评分和适用群体；关系要有端点和方向；事件要有证据及影响对象；潜变量要保留分布或不确定性，不伪装成能被准确读取的内在真值。

| 状态 | 含义 | 例子 |
|---|---|---|
| 未知 | 当前没有足够信息知道 | 不知道祖父确切出生年份 |
| 未测 | 可测但本次没有测量 | 未完成听力检查 |
| 不可得 | 有记录或方法但当前无法取得 | 机构不开放具体记录 |
| 不适用 | 概念对该对象或情境无定义 | 从未借贷者的某笔债务利率 |
| 拒答 | 本人有表达机会但不愿披露 | 拒绝报告收入 |
| 冲突待解 | 来源互相不一致 | 自述出生年与早期登记不同 |

“合成设定”属于断言来源，与上表的适用性和观测状态分别记录。合成世界可以确认某人失业，同时保留档案的具体失业日期未知、本人不愿作答。多份观测各有时间和主体，共同指向一个待解析对象。

“不知道”“没有观点”“未经历”“不愿说”和“中立”也是不同回答，不得全部合并。无依据不得用 0、平均数或民族典型值补齐。对未知可以保留区间、候选值或缺口；若任务必须生成一个值，保留它是合成假设及备选分布，不得将流畅叙述视作验证。

## 7. 关键跨族联动

| 关联 | 需要检查什么 | 不允许的捷径 |
|---|---|---|
| TIME→HISTORY→GEO | 时点、行政区、法域、制度有效期与人在何地 | 用当代法律统一检查百年前人生 |
| HEALTH↔FUNC↔环境 | 症状、诊断、任务表现、辅助支持与环境限制 | 有病即失能、身体只能折旧 |
| ORIGIN↔DEV↔EDU | 家庭机会、养育和教育轨迹如何相容 | 家庭阶层直接决定学历和人格 |
| WORK↔INCOME↔ASSET↔DEBT | 口径一致的存流量、所有权与交易链 | 收入减支出直接等于全部财富变化，忽略估值和转移 |
| PARTNER↔FERT↔HOUSEHOLD | 登记、同居、生育、养育、经济共享的不同边界 | 生育必须在登记婚姻之后，否则整体删除 |
| ETHNIC↔LANG↔RELIGION | 实际习得、参与、认同与群体内部差异 | 一个民族对应一种语言、信仰或人格 |
| HISTORY→BELIEF→GOAL | 接触、理解、信念及当时可见备选项 | 知道结局后为当年决定编造唯一理由 |
| MEMORY↔RECORD | 记忆版本、误差、隐瞒与账本的受控差异 | 人必须准确背出所有档案数字 |
| SURVEYCOM→SURVEYRESP | 理解、提取、判断、表达及模式效应 | 所有问题都有稳定、准确、无拒答的“内在答案” |

这些联动只规定需要保留的区分与审查方向，不等于已经识别出的因果模型。独立测量、相关关系与因果影响应各自保留证据等级。

## 8. 生成时的采用原则

1. 先定义目标人口、参照日期、法域和问卷用途，再选必要字段。一个人物需要足够的生活厚度，但不需要编出毫无用途的完整基因组、指纹或精确每秒轨迹。
2. 所有地区、民族和复合身份都要有表示能力；数据稀疏不能以刻板故事补齐。港澳台和历史地区保留当地类别与制度，映射需注明损失。海外常住经历可表示，但是否纳入目标人口由研究定义决定。
3. 先满足共同事件与跨人约束，再使个体差异可表达。人口联合分布、少数群体覆盖和个体可信度是不同验证问题。
4. 允许 LLM 提案，但提案中每个重要事实、主观状态和叙事细节必须区分断言类型、来源和有效时间。参数未经校准时不标“科学确定”。
5. 绝对逻辑不可能可以阻断；违法、罕见、偏离规范、创伤与记忆错误通常需要解释和标注，而不是从合成人群中清除。否则会把真实社会的困难和差异删除。
6. 问卷中显示的回答只来自作答时可知、愿意表达且能映射到选项的信息。人物档案完整度不能代替答案对真实人群的外部验证。
7. 字典不直接给心理变量绑定全国固定分布。采用量表前确认翻译、年龄、文化与测量等价性；没有本土验证的潜变量只能保留研究假设身份。

## 9. 字典的验证层级

静态检查覆盖 55 族、440 条、UTF-8 BOM、唯一维度 ID、有效跨族引用及合法的主状态层。逐条测量效度、量表和微观数据授权、联合分布校准及历史时段覆盖各有独立证据要求。族级“来源建议”仅作为查找入口，使用时必须绑定具体波次、资料页码或变量、适用范围和版本。

## 10. 从一级概念到可生成状态

### 10.1 一次写入，多处引用

把每条 `dim_id` 实例映射到唯一的语义位置：事件账本、有效期状态、关系边、本地世界规则、观测、人物视角、派生视图或问卷作答。一个 `dim_id` 可以有多条带时间及情境的实例。审查同一个实际变化时，比较涉事人、对象、场所、路径分支和时间区间，以识别重复写入。依据不足以认定两个记录指向同一件事时，先保留候选映射。

| 写入语义 | 必需信息及更新方式 |
|---|---|
| 事件 | 带时间精度的发生窗口、对象与参与者、地点或法域、发生前后状态、版本及依据。共同事件使用同一事件 ID，各方影响与认知按人记录。 |
| 有效期状态 | 对象、字段、有效起止和时间精度、状态/计量单位、生成依据。变更通过事件或显式修正关闭旧区间并开启新区间；容许未知期和有证据的重叠。 |
| 关系及资源流 | 两端主体、关系类型、方向、有效期、双方视角；资金、照料和居住使用不同边。同一次汇款在转出方、接收方及家户报表复用同一交易，注明所选家户口径。 |
| 人物视角 | 人物、题材/情境、获知渠道和日期、当时确信程度，以及公开或私下可披露范围。当前状态、持续倾向、回忆版和访谈回答按各自时间读取。 |
| 观测 | 观测对象、记录者/代答者、记录时间、被描述时点、模式与测量版本。观测可冲突、缺项或撤回，已有版本可追溯。 |
| 派生值 | 输入字段及版本、计算时点、口径、不确定性。年龄、队列、任职时长和统计家户口径按依赖重算。 |
| 问卷作答 | 题目、会话和题次、参照期、语言、访员或设备、可见证据及披露选择。单次作答归档于会话，后续若生成长期倾向需有独立证据。 |

### 10.2 一组维度可以有四类独立判断

| 层面 | 记录方法 | 例子 |
|---|---|---|
| 概念是否适用 | `适用 / 不适用 / 待判断` 并保留规则和日期 | 没有该笔债务，利率不适用。年代太早无法确认借贷是否存在，适用性待判断。 |
| 值在合成世界中是否确定 | `已确认 / 候选区间 / 未确定 / 冲突待解` | 家庭确认迁居年份在 1992–1994，保留区间并传递到入学年龄校验。 |
| 观测与回答结果 | `已记录 / 未测 / 无法获取 / 不知道 / 无观点 / 拒答 / 跳题`，附观察对象 | 被访人拒报收入，与研究者能否获得历史工资流水分别记。 |
| 依据和适用性 | 按来源、目标人群、地区、时段和抽样框记录已观测、可校准、仅支持机制或仅示例 | 一所学校的访谈可支持学籍转换机制；地区转学率需要匹配统计母体。 |

正式定量映射附数据波次、原始字段、分母或条件样本、权重、构念、计量形式、缺失策略、许可和覆盖边界。构念与题项的可比性应分别检查结构、因子负荷、截距或分类阈值，按要比较的均值或关联决定所需证据。跨年龄、跨波次、跨语言、不同自答/代答方式不可自动合并；只在证明可比的题项和口径上比较。对照缺失处理或计分规则改变前后的结果，并保留原始观测。 [Liu 等，纵向有序分类量表的测量不变性](https://pmc.ncbi.nlm.nih.gov/articles/PMC5121102/) · [Laajaj 等，多国不同方式的人格测量验证](https://doi.org/10.1126/sciadv.aaw5226)

### 10.3 时间、状态与按需补全

1. 按当前任务确定焦点人物、参照时间、世界和档案版本。出生、死亡、政策有效时间、个人获知时间、档案记录/修订时间、问卷参考期可以不同。个人年岁从参考日和出生区间派生；生理发展、法律资格、社会角色和自我感受用各自的触发条件。
2. 写入不可绕过的锚点，如存续、重要关系、教育/就业时段和居住历史。按人物所在环境、可及资源、关系义务与个人所知生成可行选项。短期状态更新用具体情境，长期倾向用纵向证据或明示假设。时代、年龄和出生队列之间有结构依赖，拟合时需要写明识别假设和替代估计。 [Elder，人生历程理论](https://doi.org/10.1111/j.1467-8624.1998.tb06128.x) · [Bell 与 Jones，年龄—时期—队列识别问题](https://doi.org/10.1016/j.socscimed.2013.04.029)
3. 将核心人生、任务模块及常规生活素材逐步实例化。关键锚点一经确定，新的饮食、地方用语、同事或一次通勤只在兼容的时间预算、知识和关系环境中生成。可反复使用的新细节有事件或状态 ID 与生成依据；一句临时措辞只存作答。已发布事实若需修正，开启新版本，并以实际依赖确定哪些状态、叙述与可重复实验结果要重算。历史作答按原会话留存。两次问卷并行补同一细节时对同一语义位置去重或留待冲突裁决。
4. 历史回放以人物当时可知的视图作答，同一真实事件容许晚到记录和迟知。在“后来回忆当年”和“回到当年作答”两个任务里选用不同视图；复用档案时先核对两个时间语义。

## 11. 逐族生成与验证契约

下表覆盖 CSV 中所有 55 个族。默认位置可以通过对象引用跨族读取；已有证据或来源冲突时按第 10 节处理。

| 族 ID | 生成与重用 | 可复核断言 |
|---|---|---|
| TIME | 出生与死亡入账，参照时点随查询输入；自然年龄和队列派生，社会角色从各自事件读取。 | 出生年月只知年份时一律保留误差，法律资格和实足年龄在生日边界复核。 |
| GEO | 分开常住、暂住、实际活动、登记地、原乡和主观地方归属，连接行政区历史版本。 | 短期培训与原居地可并存，搬迁需明确谁迁、当时称谓和区划。 |
| BODY | 按实际测量或阶段先验写入形体、身体特征、暴露和家族风险；阈值附年龄与测量口径。 | 身材跨年龄段连续性和证据精度可审查，未知遗传情况保留未知。 |
| FUNC | 逐项记录任务、环境、辅助、人协助和实际参与，链接医疗事实和地点。 | 轮椅、换楼层或搬家可改善实际活动；疾病演进须有自己的时间线。 |
| HEALTH | 症状、就诊、检查、诊断、治疗和实际康复分别入账，区分自评与临床。 | 发病可早于确诊；医疗费用可晚于支付及报销。 |
| REP | 生理阶段、医疗与当事人体验挂在人身及时间点；生育关系引用 FERT。 | 缺乏检查时生育能力未知，分清本人、伴侣及代答来源。 |
| DEV | 用早期照料、居住、营养和互动的区间版本，照料者来自共享关系。 | 婴幼儿照料的事后自述可来自转述，原照料者与居住同伴可不同。 |
| COG | 记录任务能力、测试与短期负荷，语言和教育提供上下文。 | 生病后的单次低分不触发长期能力覆盖；量表更换须先检查可比性。 |
| AFFECT | 短期体验、压力评价、调节与恢复单独更新，基线由跨情境观察或显式假设给出。 | 当下不快与长期生活满意可以共存。 |
| PERSONALITY | 倾向按较长时期表示；同一人在熟人、单位、家庭和陌生场景保留不同表现。 | 单次发言只能增加一次观测；长期趋势需要重复证据并检查测量变化。 |
| MOTIVE | 记录同一情境下并存的需要、动机、冲突及主次变化。 | 相同动机在机会变化时可生成不同动作。 |
| VALUE | 保存对象、情境、价值权衡与例外；在规范冲突中用 COG、LIFECHANCE 和关系约束。 | 一人支持普遍公平，同时在有照料义务时偏向具体亲属，两问可以得到不同选择。 |
| BELIEF | 逐命题记录信息渠道、置信、支持/反对和时间；信任细化到对象与领域。 | 不知道政策、相信政策有效和实际用过服务分别保存。 |
| SELF | 按角色、时段、听众写入自述、意义和连续感，引用但独立于事件账本。 | 新叙事不改写旧事件；允许关系中说法不同并保持视角可查。 |
| MEMORY | 事实事件与记忆版本多对多，含亲历、转述、检索线索、持续情绪和确定度。 | 能保留“那年冬天”而档案知晓具体日期；日期不得溢入人物记忆。 |
| GOAL | 对个人可见备选保存目标、时限、尝试和决定；结果引用事件账本。 | “想读书”的目标、报名和实际入学三者都可单独发生。 |
| KNOW | 按领域记录所知、误解、技能和信息获得渠道；证书从 EDU/RECORD 读取。 | 通过家人得知手续可以早于自己办理；学位无法自动补齐专业知识。 |
| LANG | 按语言/方言、听说读写、使用场域和时间维护习得及使用。 | 学校学过和在家惯用是不同断言；换题目语言可改变有效作答支持。 |
| ORIGIN | 出生家户、父母与监护者履历、代际支持用关系与家户边，继承引用原事件。 | 同胞排行须声明同父母/同家户等口径，离家入户有独立记录。 |
| PARTNER | 法律登记、双方认可关系、婚礼、同住、资源分配与安全分项引用。 | 分居可早于登记解除；伴侣对关系质量可各有版本。 |
| FERT | 生育结局入事件账本，生物、法律及社会照料分别成边；按人记录意愿。 | 一次出生被家庭和多个主体共同引用；未同住父母仍可有汇款证据。 |
| HOUSEHOLD | 住所共同体、开支共同体、监护与照料分别有效，家庭成员可以变动。 | 同住祖父母可负责照料却非人事档案中的监护者，户籍簿不代替实际成员。 |
| SOCIAL | 关系端点、双方称谓、接触、信任、支持与边界按时段取值。 | 朋友关系可有两方不同的亲密评价，实际互助单独留痕。 |
| CAPITAL | 分别建模关系可联络、资源可动员、对方愿供给与已获得，以及外部声望。 | 有亲友在某行业，若失联或资源冲突则未必形成就业推荐。 |
| ID | 使用当时法域的登记、行政资格与证件状态；对外只用合成标识。 | 当时无该类别或证件制度时，字段标适用性，保持原分类未映射状态。 |
| ETHNIC | 把官方登记、自称、被归类、文化继承、实践及歧视证据分开。 | 允许多重归属、分类口径不对等或本人未申明；地区特征不能自动填进个人字段。 |
| RELIGION | 信念、仪式、社群、公私身份和日常实践分别记录。 | 为亲属参加仪式只证明参与，个人信仰仍看自述证据。 |
| POLITY | 围绕制度角色、服务互动、政策知晓、参与和效能感分别写入。 | 参加一次公共活动不会覆盖私人态度或政务权利。 |
| EDU | 入学、在读、留级、中断、离校、证书、训练和择校机会引用学校和制度版本。 | 缺证书的人可有真实技能；历史教育分类的现代等价标明依据。 |
| WORK | 保存岗位、组织、合同、地点、排班、实际劳动和报酬权利的独立状态。 | 拥有劳动关系、记账收入、当期实际出勤可呈现不同组合。 |
| CAREER | 求职、转岗、退出、再就业和退休是 WORK 时间线上的事件或制度转换。 | 找工作可与当前任职、照料、零工重叠；实际工作时段仍受资源约束。 |
| INCOME | 交易按账户、主体、发生与支付时间、名义价值、币种、金额精度和渠道记账。 | 汇出入形成一对，家户内部转移统计时按口径去重；拖欠不当到账。 |
| ASSET | 记录权利束、权属主体、持有期、估值日和对应交易或继承，涉及共有时明示份额。 | 因估值上涨而增资产无需形成对等现金收入；拥有住房与能出售分开。 |
| DEBT | 写入债权人、债务人、提款、利息、余额和偿付事件，关联拥有者、担保与转让。 | 申请额度不等于提款金额；逾期可发生于现金不足，也可来自纠纷。 |
| WELFARE | 保存制度窗口、资格、参保、申请、批准、领取及跨地转移；引用有效法域。 | 符合资格但未知、未申请、失败或未到账分别可表示。 |
| CONSUME | 分开需求、主观偏好、渠道获取、搜索、购买、实际使用和评价。 | 自报愿意买不增加支出，评价可能来自借用或家人购买。 |
| HOUSING | 与 GEO 共用地点 ID，小区、房屋、室住人、产权人和居住权分别关联。 | 迁居和产权转让可不同步；水电网络只依当地时期与实际接入生成。 |
| DAILY | 用工作日、休息日、季节和阶段的日程模板，登记主活动与可并行活动。 | 当地正常民用日的主活动总占时在当天范围内，打电话和照料可被共标。 |
| FOOD | 记录所食、预算、供应、烹饪场景、偏好、禁忌、体力活动及变化。 | 喜欢的食品可能因供给、价格或健康建议而未消费，禁忌与实际摄入各有证据。 |
| LEISURE | 分开兴趣、机会、单次参与、长期投入和共同社群；从 DAILY 读取真实耗时。 | 无时间参与不等于失去兴趣，和他人共玩需各方在场或可联网。 |
| MOBILITY | 用出发点、交通方式、耗时、票价、无障碍、管制与日程刻画可达性。 | 直线距离近但可达性低可成立；技能、票价、末班车适用到具体时点。 |
| DIGITAL | 记录本地网络可用、家户设备、个人接入、平台使用与他人账号代办。 | 看到网页、相信消息、发布内容、产品有账号分别留痕；未推定使用全民设备。 |
| COMMUNITY | 按地域和时期存基础设施、组织、非正式规范、产业与公共服务的世界状态。 | 相邻地区的可用性不互抄，地方惯例不会成为每个个体的规范答案。 |
| ENVIRON | 保存外部危害与污染、个体暴露、损失、协助、环境态度及其时空范围。 | 同省并不足以证明接触；同一险情的灾害 ID 与个人暴露 ID 必须可追溯。 |
| HISTORY | 世界节点、政策执行、暴露、机会和反馈引用历史规范与人物账本双方。 | 历史节点进入档案前须有渠道、地点/时间和受影响角色，允许只获知而无变化。 |
| RECORD | 每份记录可版本化，含作者、目的、观测对象、日期精度、可能误差和访问权限。 | 姓名或事件归属冲突时留原件引用；修正不得给旧视角增加后见知识。 |
| DEATH | 死亡事件终止本人的生存线；生前意愿、临终过程、记录发布与遗属处分独立。 | 问卷时点超过死亡时限制输出为明确的档案叙述；纪念和遗产仍可关联其记录。 |
| SURVEYCOM | 建立会话需求：语言、参照对象、经验资格、记忆检索和数值估计。 | 不会读题和不知道答案分开；代理回答保留代理人与可知范围。 |
| SURVEYRESP | 对题目记录选项映射、作答模式、披露、顺序与复测；回答是会话事实。 | 模式变化可以改变答复；过去的作答保持原样以供审查。 |
| PROV | 为世界、人生、观测、派生和问卷断言附生成、依据、许可和修订谱系。 | 任何定量或事实性输出能定位到适用来源或明示合成假设。 |
| PREF | 记录偏好的对象、情境、取舍、习惯触发和可观察决策，多次重复后才更新倾向。 | 同样的价差在自费、单位报销和送礼场景可产生不同选择。 |

## 13. 可直接检查的样例与数据边界

### 13.1 两个相近人生，多个时点与视角

- **同一笔钱、三种家户位置。** 合成家庭中，一位父亲到外地工作，起初孩子和母亲一起留在原居地，随后孩子与父亲团聚，祖父只在假期提供照料。先写共同亲属关系、孩子与父母各自的居住区间，写同一笔汇款的收付双方，按观察时点计算共居家户，再写学籍、照料、通勤和母亲对安排的理解。冻结其他条件再减少交通可达性，重新比较见面次数、汇款是否继续发生、转学入口和长期影响。对 2010/2020 人口普查的留守分类保留原分母、空间和年龄口径。可用它做截面校准，迁移期间的个体转移速度需另有数据。 [北京大学 CFPS 家庭成员关系/家庭经济构成说明 §1.1](https://www.isss.pku.edu.cn/cfps/docs/20241104091003466564.pdf) · [农村留守儿童普查分析 §2.4](https://doi.org/10.1007/s42379-024-00159-2)
- **回家住与成为全职照料者可各自成立。** 合成青年一边准备招考、一边给家里做饭并短期接活；另一人因父母失能回家照料，暂停求职。用 DAILY、WORK、CAREER、HOUSEHOLD、INCOME 写入实际工时、求职活动、养老金/父母转移与照料时间，媒体概念仅作为角色可能见过的自称或第三方标签。原始采访可以证明机制有实例，调查口径与抽样数据决定人群频率。 [AP 对返家青年、家务与找工作的采访](https://apnews.com/article/aeddf9fd7c188db7d72dbb3cca6ebbf7)
- **观测差异和人本身变化可以同时发生。** 同一人物在两期问卷分别以个人自答和家属代答报告心情。将两条写到不同 `RECORD.01`，数据以相应问卷版本和参照窗口绑定 `MENTAL.02`。只有在任务确认可比并获得充分支持后才做潜在状态更新。对于 CFPS2022 CES-D8，官方说明原始条目取值 1–4，与 0–3 编码的工具有差异，项目另给 CESD20sc 桥接派生值。保留原始分、计分版本、转换依据和适用群体，缺项者不擅自补分或回推诊断。 [CFPS 2022 数据清理报告 §3.2.3](https://www.isss.pku.edu.cn/cfps/docs/20241104091003466564.pdf)
