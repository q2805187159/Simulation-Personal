# 跨学科依据与机制补全

本文件提供构念、候选机制与可检验反例。对象身份、共享事件、图修订、人物视角和验收标识遵循[全链路设计复核与统一契约](全链路设计复核与统一契约.md)。定性来源可支持机制与场景定义，参数按对应风险集、时期及人群独立估计。

资料复核日期：2026-09-29。本文是从来源到设计的推导记录。**文献结论**与**本项目提出的模型结构**分开：前者有适用样本与理论边界；后者是待检验设计，不能借文献权威当作已被验证的人类生成规律。目录中的“族”表示维度分组，和民族不同。

## 1. 人类构成不是一个分数体系

建议采用六个相互关联的解释尺度：身体与功能、个人心理与行动、关系与家庭、组织与制度、文化与历史、观察与作答。每个尺度都应能表达事实、主观感受、行动机会与观测误差。只增加人格指标，会丢掉“他想做但没有机会”“他做了却不愿说”“他记错但不是系统事实出错”等关键差别。

### 从研究到设计

|---|---|---|---|

## 2. 哲学不是心理量表：把思想转换为可讨论的问题

哲学能提示遗漏的解释层次；它的规范性命题不能直接成为人口分布或生成参数。下面是**本项目的概念借鉴**，不声称各种传统可以压缩成一个分数。

| 哲学/思想视角 | 对人的问题 | 可记录的经验性内容 | 必须保留的分歧 |
|---|---|---|---|
| 儒家关系伦理与修身 | 自我如何在家庭、礼和角色责任中形成 | 亲属义务感、角色冲突、礼俗参与、修养实践、他人期待 | 传统内部和当代解释多元，不能把孝顺或服从当中国人默认人格 |
| 孟子、荀子等人性与养成讨论 | 禀赋、习惯、学习与环境如何关联 | 个人对成长原因的解释、学习/教养经历、道德自我评价 | “性善/性恶”是思想立场，不是科学测量到的群体本质 |
| 道家及庄子 | 人对变化、标准、功名和处境的反思 | 控制/接纳策略、对成败的意义解释、角色距离、生活取舍 | 不将无为等同消极，不以地域/民族推断认同 |
| 佛教相关思想 | 痛苦、变化、依恋、自我与修习如何被理解 | 实际宗教认同、修习、宗教团体参与、丧亡解释和精神支持 | 世俗接触不等于信仰；各传统和个人实践不能混同 |
| 现象学与具身认知 | 身体、空间和他人如何进入经验 | 疼痛/疲劳、身体感、环境可达、互动情境、习惯技能 | 这不是证明模型有意识，也不说明文字档案能复制主观体验 |
| 能力方法（Sen/Nussbaum） | 有资源是否意味着拥有真实行动机会 | 资源、转换条件、可行选择、实际实现、主体所珍视的生活 | 规范性自由/福祉标准不是单一行为预测模型 |
| 自我与个人同一性讨论 | 人如何在记忆、身体、关系和变化中被视为同一人 | 生命叙事、身份连续/断裂、自我解释和他人认同 | 不用一项“身份稳定度”宣称解决哲学上的人格同一问题 |

儒家与道家等不应只被赋给某些民族；现代中国人的思想可能通过学校、家庭、职业、媒介、宗教、跨文化生活、个人阅读和经历形成，并呈混合或矛盾状态。人物可以不了解任何哲学名词，却在实践中采用某种处事方式；也可以读过经典但不认同它。把“接触”“理解”“认同”“实践”和“他人归因”分开。

## 3. 必须新增的机制表达

### 3.1 生物—心理—社会互动

例如迁移受阻不能只写“保守”。可能是缺少钱、照料责任、身体限制、语言不通、工作资格、对风险的判断、留恋社区或组合原因。模型至少表达能力、机会、动机、关系义务与可替代方案。此为机制结构提案，不是已识别的因果系数。

### 3.2 情绪和身体的短期状态

问卷时的疲劳、疼痛、饥饿、压力、情绪、注意力和在场他人可以影响理解/表达。它们不宜倒写成永久人格，也不能把一次回答作为长期态度的完美测量。状态只在任务必要时实例化，并保持时间一致。

### 3.3 多种因果与无唯一归因

每个选择记录：可见选项、资源/资格约束、个人预期、关系影响、习惯/自动反应、偶然条件、结果与事后解释。系统保存生成机制，并允许人物给出不同于生成机制的自我归因；两者不能互相冒充。相关、机制假设、生成理由、个人解释和已识别因果效应须分级。

### 3.4 历史知识与人物知识隔离

世界节点存在 → 人物有机会接触 → 实际接触 → 理解/误解 → 采信/怀疑 → 行动/不行动。每个箭头都可能不发生。系统知道互联网、疫情或某政策，不代表人物在对应年份知道全部事实；亲属有某病历，也不代表人物有权限或知道该内容。

将这条链路落到具体政策、地区产业、灾害和公共卫生节点时，使用[《历史节点与环境暴露目录》](历史节点与环境暴露目录.md)中的资格/地点/时间、接触渠道、阶段、维度映射和证据状态；按人物生成的完整流程、分支契约和验证要求见[《历史暴露推演与个人路径机制规范》](历史暴露推演与个人路径机制规范_v1.md)。目录里的群体统计与机制假设仍不能替代人物证据。

### 3.5 记忆是版本，不是可编辑事实

事实“1993 年去广州”，人物可能说“九二还是九三来着”；不改账本来适配回忆。若两份档案冲突，保留来源和证据等级。记忆可被再提取、再解释，不能把“亲历永不衰减”“新闻每年固定衰减30%”设为科学定律。关键记忆可以持久，但参数与人群差异必须实测。

### 3.6 意愿—行动差距与反常路径

“重视家庭却长期在外工作”“觉得应早点婚但选择不婚”“想运动却长期不动”不必是逻辑错误。先检查资源、机会、冲突目标、习惯与时间约束；“核心矛盾”也不应是每个人必须被戏剧化塞入的文学配方。

### 3.7 生命周期与观察偏差

从当前存活人口抽样，必然无法直接代表历史上全部出生者；已故人物需要按出生队列/死亡队列/历史截面定义不同抽样框。调查非应答、追踪流失、机构人口缺失和仅有识字者/精英史料等都会影响人生分布。古代或近代人物要用当时分类与资料精度，不能强套现代学历、民族登记、量表或制度。

### 3.8 把人生看作并行轨迹和普通日常

**争论。** 按主线选几个大事写传记，能形成易读的故事，容易把几十年的工作重复、非正式学习、寻医、照护和日常交往压空。按天穷举又会把资料贫乏的年月写出虚假的精度，也诱发日程互斥错误。生命历程研究强调历史处境、发生时机和关联生命，毕生发展研究强调增长、维持与损失可能同时出现，生态发展模型则把持续的日常互动视为发展的过程。[Elder 生命历程原文页](https://onlinelibrary.wiley.com/doi/abs/10.1111/j.1467-8624.1998.tb06128.x) [Baltes 原文](https://www.imprs-life.mpg.de/25277/022_baltes_1987.pdf) [Bronfenbrenner 与 Morris 原文](https://www.childhelp.org/wp-content/uploads/2015/07/Bronfenbrenner-U.-and-P.-Morris-2006-The-Bioecological-Model-of-Human-Development.pdf)

**取舍。** 用并行的居住、教育、劳动、关系、健康功能、照料和资源区间承载一生。区间内保留有证据支持的常规节律，例如一般工作日、休息日、农忙季、夜班周和就诊日。只有涉及关键决策、问卷题或安排冲突时展开细时段；同一次展开的事实引用同一快照。未展开表示分辨率较粗，`unknown` 表示资料仍未知，经足够观察确认的空白才允许标为无事件。

1. 在同一时间窗按本人计算主活动的互斥时段，用覆盖区间检查活动总量，不机械累加可并行的次活动。允许一边通勤一边听音频，也允许家务与低强度看护叠加；需要全程陪诊、现场值守或跨地到场的任务按地点、交通与强度检查。跨夜班用实际时间线分段，跨时区或时钟变更按实际可用时长核对。
2. 对接 `DAILY`、`MOBILITY.03`、`WORK.05`、`HOUSEHOLD.04–08`。记录需求时窗、本人可投入时窗、前后交通、主/次活动、并行条件、未覆盖的时段和可信精度。在资源账本同时检查现金、信用与赊欠、可用工具和住房容量，允许可解释的过载、欠付、推迟和需求落空。
3. 群体校准分别估计参与率、参与者时长及全体时长。国家统计局 2024 年第三次全国时间利用调查的无酬劳动参与率为 75.6%，参与者日均 2 小时 45 分钟，全体日均 2 小时 5 分钟。调查对象为抽中户中 6 周岁及以上常住成员，5 月现场收集一份工作日和一份休息日日志，以 5/7、2/7 汇总。将模拟作息投影到相同的活动分类与日志精度再比较。跨时代、地区、季节或家庭日程的联合分布不足时保留不确定性。[国家统计局调查方案与样本](https://www.stats.gov.cn/xxgk/sjfb/zxfb2020/202410/t20241031_1957217.html) [活动定义、用时与加权](https://www.stats.gov.cn/sj/zxfb/202410/t20241031_1957216.html) [分组结果](https://www.stats.gov.cn/sj/zxfb/202410/t20241031_1957215.html)

身体的发展同样使用并行轨迹。疾病、症状、自评健康、诊断记录、治疗、身体功能、环境支持和日常表现各有自己的有效期。某人诊断未变、走路距离下降、因辅具或无障碍改造恢复社会参与，可以同时成立；复诊中断也可能影响可观察性而无从确定病程。退学后学习、退休后返聘、丧亲后的兴趣与睡眠变化，均可与原有身份、知识及习惯并存。

### 3.9 把能动性落实为当时可能发生的选择与尝试

**争论。** 从家庭、地区和政策直接推出结局会抹去行动余地。反过来，把选择全部服从于稳定人格或理性最优，也会抹去资质门槛、实际协商和找不全选项的代价。Sen 区分可实现的生活方式及已实现状态，并另辨能动性和福祉；Simon 讨论信息和处理能力受限时的选择。两者用于定义对象和检验边界，参数需由具体人群与场景校准。[Sen 原文](https://www.philosophy.rutgers.edu/joomlatools-files/docman-files/11AmartyaSen.pdf) [Simon 原文](https://pages.stern.nyu.edu/~dbackus/Exotic/1Time%20and%20risk/Simon%20QJE%2055.pdf)

对会改变后续分支的节点，按顺序保留以下信息。普通习惯性行动可引用已建立的节律和规则。

| 要记录的状态 | 生成与校验 |
|---|---|
| 真实可达的机会 | 按时点检查原始资源和实际转换条件，记录地区、资格、材料、服务名额、费用、交通、语言、身体功能、照料与对方同意。资源存在、可被本人动员、能转化为实际机会是三种状态。机会是否存在不确定时保留未知。 |
| 人物认为存在的机会 | 保存当时知道哪些选项、从何得知、相信什么、何时知悉、检索成本和对未来的估计。真实可达而本人没听说、误以为走不通、误以为能办成均可。人物可试探一个现实中走不通的选项，后续写申请失败、修订判断或继续误信。 |
| 偏好、理由和权限 | 保留可冲突的目标、最低能接受的条件、对成本的主观看法、习惯和关系压力。区别本人决定、家庭协商、代办、遵从规则、被迫发生和退出受阻。允许经有限搜索接受“够用”的选择，允许延迟、维持现状、放弃和没有形成打算。 |
| 兑现、失败和反馈 | 分开提议、承诺、申请、决定、实际行动与结果。行动后的本人归因、亲友解释和证据归因各自保存。结果消耗时间/资金、更新可见信息和能力，成为接下来时段的条件。 |

这些对象对应 `LIFECHANCE.01–08` 与 `GOAL.03–08`。一个决策可由多人参与和几轮协商形成。若运行时比较“另有可用照护时是否迁移”，固定分支点之前的版本、关系和环境，切换指定条件后重新计算后果，保留进入比较的原始假设和不确定性。两条分支是反事实模拟；观测对照、识别设计与外推范围单独说明。

### 3.10 从亲属标签生成有时窗的照料、支持与家庭分工

**争论。** 个人独立生成再拼家庭，会让一位祖母同时在两省照护、同一笔汇款重复增加家庭收入。把整个家庭视为同一行动者则掩盖协商、权力差异、成员分离以及照料未落实。Giles 与 Mu 使用特定时期的中国农村数据，报告父母健康与成年子女务工迁移的关联在有其他潜在照护手足时减弱，说明应看见居住地之外的替代者。深圳一处小区的迁居祖辈访谈则揭示照料迁移可与居住拥挤、养老计划和社交网络变化同时发生。前者提供经验机制，后者支持发现情景分支，两者适用范围随样本保存。[Giles 与 Mu 原文](https://read.dukeupress.edu/demography/article-pdf/44/2/265/883620/265giles.pdf) [深圳迁居祖辈研究](https://link.springer.com/chapter/10.1007/978-3-030-67615-5_2)

- 亲缘/法律、住处、共享经济、情感关系、实际照护、出资和权力各作独立带时间的边；类型可重叠，也可相互缺失。角色和亲密度不能充当某次照料的发生记录。对重点人物建立足以约束其轨迹的共同世界，关系次要人物保留必要区间，后续补写时引用同一身份及既有事件。
- 一次共同事件使用一个标识，并注明角色、地点、有效时段、承诺与发生的分别状态。照护任务可记录需求人数、预计/实际时长、是否需到场、提供者、未满足量；同步更新被照护者得到的服务和提供者的时间支出。实际接受一段照护时若换人分段或两人共同承担，分别记录投入，需求覆盖只结算一次。金钱转移同时记出资方与收款方，在共享经济单元汇总时核销内部转移。
- 家庭成员可就同一事件各有记忆与归因。赠与、借款、共同支付和口头承诺先分开；事实有分歧时保留证词和记录差异，生成器不能靠任选一方叙述结算两边状态。家长离家或家户分户只结束相应活动/共同居住区间，照料、联系和转移按各自事件更新。CFPS 项目方对婚姻、离婚、离家带来的家户变化和追踪流失有明确设计，适合评估合成数据是否捕捉到跨户状态，使用时必须继承其抽样、追踪与失访口径。[CFPS 项目与追踪](https://www.isss.pku.edu.cn/sjsj/cfpsxm/index.htm) [Xie 与 Hu 方法原文](https://www.isss.pku.edu.cn/cfps/docs/20201225093508045085.pdf)

**合成场景。** 一位县城家长出院后需连续六周在周二和周五上午有人在场陪诊。甲在外地轮班，乙住同县但有工作与托育，邻居只愿临时代接一次，县医院之外的照护服务需要按实际地方条件校验。

| 分支运行 | 应产生的事实与例外 |
|---|---|
| 雇主同意调班，乙承担周二，甲出资购买周五服务，服务核实可用 | 记录乙实际陪诊及其交通，甲支出与服务供方收款并对账。父亲原有照护需求持续到复核时，甲的轮班和长期住地无需随出资自动变化。 |
| 服务有名额但人物没听说，乙短期无法调班，甲请假返乡两周 | 发起求助后保留当时可见选项；两周内更新甲实际在场、交通及已确认的缺工/薪资。两周后仍有覆盖缺口时逐段记录，无从核实的缺口注明未知，确认未满足的需求才标记未满足。 |
| 甲乙都维持现有工作安排，亲友临时替班一次，其余照料落空 | 交易只结算该次服务，可以发生少做一次检查或改约。无法确认健康影响时保留未知，也无法凭一次缺席推断家庭关系破裂；候补照料者需要有可用关系与时段。 |

对生活史新闻使用其一手访谈作为情境材料。AP 2023 年关于成年子女回家生活的采访给出求职、学习备考、与父母分担家务和获得零用钱等不同组合，有助于设计可问的细节。自述标签、劳动力统计中的就业状态、实质收入来源按各自口径编码；不用采访个案推断全国人数、比例和共同动机。[AP 一手采访](https://apnews.com/article/china-youth-unemployment-jobs-economy-aeddf9fd7c188db7d72dbb3cca6ebbf7)

### 3.11 从个人世界到自我解释、回忆与回答

**争论。** McAdams 与 McLean 把叙事身份理解为持续发展的自我故事，并讨论文化与因果证据的边界。哲学家 Strawson 质疑人人都以完整人生故事经验自我，也质疑把叙事性当成好人生的标准。《论语·里仁》4.18 同时谈侍亲与委婉劝谏，呈现角色义务下也可能发生意见冲突。项目保留世界轨迹的可追溯性，同时允许人物用片段、意义摇摆、相互冲突的价值或简短实用的语句理解自己。角色可以通过家人、学校、阅读或媒体引用经典，也可以身处相关实践环境却从未接触这些文本。经典诠释作为思想资源使用，群体频率取自合格调查。[McAdams 与 McLean 原文](https://is.muni.cz/el/phil/podzim2013/PSB_443/um/5__Oct_29__Narrative_Identity.pdf) [Strawson 原文](https://web.ics.purdue.edu/~drkelly/StrawsonAgainstNarrativity2004.pdf) [《论语》原典和释义](https://www.chinakongzi.org/eBook/analects/one/files/basic-html/page209.html)

| 调用视角 | 数据内容与判断 |
|---|---|
| 发生层 | 事件、参与角色、时间与地点、接受的系统状态变更、冲突和证据状态。合成人生的已确认事实只在其对应世界版本中成立。 |
| 当时的经验与所知 | 使用当时已取得的信息、身体感受、想法、期待及来源渠道。现今诊断、自称和后验解释不反向填入人物当时认知。 |
| 后来的回忆和解释 | 保存可检索线索、精度、信心、对事件的情感、来源类型与当前意义。允许直接亲历、他人转述、后见材料、听过但信源不明等不同来源；回忆起的地点和日期允许有依据的错位。 |
| 具体作答或讲述 | 以答题时快照、回忆区间、受众、语言和问法进行检索及表达。人物可以回答大概日期、缺少记忆、知情但拒答，或采用经语用消歧后的表达。调查员的提示进入调查上下文，只有有独立授权的后续人生事件才写入长期状态。 |

Conway 与 Pleydell-Pearce 的理论支持把线索和当前目标作为检索机制。北大 CHARLS 2014 年生命历程问卷提供童年、居住、家庭、教育、工作和健康等回溯模块，可用来对照可提问的资料项及其时间精度。其工作史主模块要求六个月及以上的工作，因此查无此项可能源于采集规则，仍允许更短的工作事件。Belli 等人的访谈实验表明事件日历对部分迁居和就业项目改善回忆质量，外推到其他参照期、题目和访谈方式需要检验。验收可比较同一题有无已知参照线索，以及本人回答与家属代述，分别观察时间区间、信心和缺失原因。误差分布由真实纵向或重复测量校准，无法校准时保留机制假设。[自传记忆原论文](https://pubmed.ncbi.nlm.nih.gov/10789197/) [北大 CHARLS 2014 问卷](https://charls.charlsdata.com/Public/ashelf/public/uploads/document/2014-charls-wave3/application/CHARLS_Life_History_Questionnaire.pdf) [事件日历实验摘要](https://pubmed.ncbi.nlm.nih.gov/11264054/)

同一查询应区分事实发生时间、档案登记/修订时间、人物获得信息时间及作答时间。例如 2001 年离职、个人记成 2002 年、档案 2025 年才补录，可以同时存在。后出的记录可更正历史事实视图，但查询当年的人物视角禁止泄漏后来才获得的信息。已故人物的生平在死亡处结束，继续存在的是家属解释、代述及档案修订；需要第一人称时关联生前截面，明示它是依据该时点资料生成的回放。

### 3.12 机制级验收与反例

| 校验对象 | 固定输入与对照 | 预期对象变更与验收 |
|---|---|---|
| 平常日程及冲突 | 固定跨县通勤时间和工作班次，增加需要在场的陪诊；另用通勤期间听音频为可并行对照 | 必须改班、换人、延期或记录未满足。听音频可和通勤重叠且不延长日程。静态检查定位日期区间及冲突的活动标识。 |
| 关联生命与共享事件 | 同一家庭从两个成员视角读取同一笔汇款、共同陪诊及分户前后的状态 | 共同事件使用同一标识，钱款及服务唯一结算，允许关怀动机的说法不同；分户后仍可存在转移及照护。 |
| 机会与行动 | 真实有服务但本人不知、本人误信有名额、本人知情且具资格但家人未同意 | 分别保留可行集、知情集、尝试及结果；当时快照禁止出现事后信息。未选路径保留可解释的条件，缺少证据的选项有未知态。 |
| 功能与发展 | 同一疾病下给不同人物不同环境/辅具，并比较同一人物干预前后 | 疾病状态可相同，功能表现及参与可不同。恢复、反复、未测与代偿使用各自的状态变化。 |
| 叙事与回忆 | 同一人用不同线索被问到搬迁；两个人对同一共同事件有不同解释；一人不讲统一人生主题 | 账本、查询快照和事件标识一致，记忆精度/解释可变化或为空。没有固定故事风格、线索改善概率或正向结局门槛。 |
| 时间与生死 | 对有后补档案的已故人物查询生前界面及家属访谈，再尝试延续原人物行动 | 生前截面只可用截至当时知情的信息；家属访谈作为后续独立观察；已故人物的行动事件被阻断，档案变更另有有效时间与登记时间。 |
| 数据有效性 | 对 CFPS、CHARLS 等独立留出中的重复区间、事件间隔、家庭组成变化和可观测作答做对照 | 同时报告区间覆盖、转换/停留时间、共同事件一致性、缺失结构和回忆偏差；按来源或适用人群分层。缺乏样本的时期与群体标明不可评估。 |

实体身份、因果时间、互斥活动和共享事件的守恒检查属于结构验收。家庭过程、发展、回忆概率、测量差异和叙事风格属于实证或情景验收，先按来源确定可检验总体、口径与比较条件。引用可作为结构依据，实际通过需要生成样本及独立数据。

## 4. 需要取消或降级的旧规则

| 旧表达 | v3 处理 |
|---|---|
| 身体健康只折旧不回本 | 可恢复、治疗、康复、学习与辅助代偿；健康与功能不等同 |
| 母子年龄差固定在某区间，生育只许18–48 | 区分生物关系、收养/辅助生殖、资料错误；经验范围是风险/罕见度，不作普遍绝对边界 |
| 先育后婚一律违规拦下 | 生育与法律登记、仪式婚、同居是不同事件；可记录违法/非正式处境及后果 |
| 2016年前二孩全部违规 | 按地方、时期、民族/夫妻身份及例外核对；政策适用和实际发生分开 |
| 1998年前不可能有房贷 | 1998文件本身说明修改更早的试行办法；不能用改革标志年判定“之前不存在” |
| 未签劳动合同就无社保 | 劳动关系、参保资格、实际缴纳、补缴/转移和权益分别记录 |
| 两份全职工作永不能重叠 | 先辨合同/实际工时/任职记录/交接/兼业；24小时等资源约束与合法性分开 |
| 同村同年不能同时出现旱涝描述 | 地点更细、季节不同、事件先后不同、记忆不同均可能；只阻断同一时空不可共存的断言 |
| 收入-支出=资产增量 | 区分现金流、债务、转移、继承、估值变化、折旧、账户口径和家庭/个人归属 |
| 人格每十年变化固定上限 | 无量尺/基准/群体验证就不设“科学阈值”；可用经验分布与异常复核 |
| 每一种态度必须有一个显式经历原因 | 社会化、一般学习、未记录因素和测量噪声均可能；不能强造专属创伤解释 |
| 生成后由同一LLM给自己打分即证明可信 | 独立规则/来源、独立数据留出、专家/群体审查和误差报告共同验证 |
