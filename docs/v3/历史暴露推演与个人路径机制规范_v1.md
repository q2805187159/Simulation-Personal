# 历史暴露推演与个人路径机制规范 v1

资料复核日期：2026-09-29。本文规定历史资料如何进入暴露判定、候选生成、状态投影和验收。标识、时间查询和图版本采用全系统统一契约。 [全链路设计复核与统一契约](全链路设计复核与统一契约.md)

## 1. 设计对象

| 对象 | 标识与语义 | 所属记录 |
|---|---|---|
| 历史节点 `HistoricalNode` | 以 `historical_node_id` 和节点版次定位灾害、政策、经济、公共卫生或技术变化 | 外部世界资料目录 |
| 环境快照 `ContextSnapshot` | 查询指定时空和世界资料版本得到的规则、市场、服务供给与信息条件 | 可回查的环境查询结果 |
| 暴露记录 `ExposureEpisode` | 以 `exposure_id` 记录人物、家庭或组织与历史节点的分渠道时空匹配、接触判定及依据 | 关联历史节点版本与人物图版本 |
| 机制假设 `MechanismHypothesis` | 候选路径采用的机会、资源、关系与行动机制。保留证据层级、替代解释和适用范围 | 运行输入及参数依据 |
| 事件或机制候选 | 以 `candidate_id` 引用可发生、延迟、失败或无变化的选项 | 生成运行及选择审计 |
| 人生事件 `LifeEvent` | 以 `event_id` 记录已采用的合成事件，或有独立依据的经历 | 带 `graph_revision_id` 和 `branch_id` 的人生图 |
| 状态增量与人物视角 | `StateDelta` 记录事件对参与主体的状态变化。知识获得、回忆及解释分别记录，可引用同一事件 | 版本账本和按角色读取的投影 |

“真实感”由事件顺序、资格、地点、资源、关系和状态变化共同支撑。一个事件可以真实存在，个人可能没有接触；个人可能接触了，但不理解/不采信/不行动；有行动也可能没有研究所预测的结果。生成器需要保留这些缺口。

### 1.1 把相反的解释转成可验证分支

| 设计张力 | 实现决策 | 应观察的差异 |
|---|---|---|
| 历史结构塑造选择，个人仍面对多条可行路径 | 时空、制度与资源先限定行动集，再由关系、当时目标、风险、机会成本和日程生成行动或未行动；现实供给缺失时可行集自然缩小。Elder 的生命历程视角支持按生命阶段和共享关系追踪历史作用。 | 同一批复工的两位员工可能分别到岗和在家照料。两类结果都需要可定位的单位、个人和家庭约束。 [Elder 生命历程研究](https://doi.org/10.1111/j.1467-8624.1998.tb06128.x) |
| 制度承认一项权利，兑现仍取决于能否使用 | 参考 Sen 的能力方法，把规定权利、可选择的现实选项和已实现结果分别入账；依次核对供给、交通、时间、现金、语言/沟通和代理申请条件。能力方法用于设计取舍，不能产生领取率或统一的生活价值分。 | 同样拥有申请资格的两户，一户等待床位，一户使用上门护理。对同一人询问资格、享受过与评价服务应得到不同证据支撑。 [Sen 的原始章节](https://doi.org/10.1093/0198287976.003.0003)，[能力与实现的定义](https://plato.stanford.edu/entries/capability-approach/) |
| 历史可能对参与者和旁观者产生相反方向的影响 | 为事件设置清楚的研究对象、暴露角色和结果。下乡青年本人的收入或工作、接收地儿童的教育，分别调用对应研究并保留地方性与选择偏差。 | 城市青年失去一段城市求学机会，同时接收村的部分儿童可能获得额外的学习接触；在两个不同人物账本中分别检验。 [下乡青年结果再评估](https://doi.org/10.1016/j.ssresearch.2007.08.002)，[接收地教育研究](https://doi.org/10.1257/aer.20191414) |
| 大事具有可讨论的影响，小事和长时间的稳定同样组成一生 | 在匹配历史节点前先推进当前日程与已存在的工作、学校、住房、债务和照护状态。多个节点只竞争或改变与其相交的普通事件；无事件年份仍保留状态持续、关系变化与日常印迹。 | 删除一条新闻接触时，人物照常工作，相关记忆可消失；删除唯一护理替代选项时，照护计划应该重新求解。 |

## 2. 七阶段生成链路

```text
总体/人档快照
  → 版本化环境查询
  → 适用资格筛选
  → 个人/家庭暴露判定
  → 机制候选与可比较的替代路径
  → 事件候选和状态增量
  → 独立校验、证据标注和时间点快照
```

### 阶段 A：锁定人物输入

固定人物 `person_id`、所用图修订 `graph_revision_id` 及分支 `branch_id`。用 `snapshot_id` 固定投影结果，保存查询有效时点 `as_of` 和档案登记截止点 `archive_as_of`。输入包含生存状态、日历与年龄精度、当期关系、居住和活动地点区间，以及已确认的状态。缺失地点保持 `unknown`，出生籍贯只按其有效的语义参与匹配。

### 阶段 B：查询节点与环境

按生命周期搜索出生/成长地、学校/单位、通勤/迁移路径、家属位置和服务机构。每个查询保留行政区划版本、空间精度、时间有效期、数据源版次和检索条件。对只有月、年或口述范围的日期，保存最早和最晚可能时点。轨迹和暴露的确定窗口相交且证据足够时才能确认，只有可能区间相交则保留候选。跨时区或跨日业务使用当地日期和时区；历史历法保留原写法及换算精度。

### 阶段 C：计算适用资格

按节点类型解释条件：灾害需要空间范围、发生时段和在场/脆弱性；政策需要法律有效时间、地方执行、人员/家庭身份和办理/服务记录；企业调整需要行业、单位、岗位和企业阶段；教育中断需要年龄、学校、就读轨迹；公共卫生事件需要地点、接触、职业、学校或管控范围。

每项资格用 `eligible|ineligible|unknown|not_applicable`，并保存人员、岗位、公共服务或家庭的资格主体。上位政策、地方细则及机构处置分别记录效力和日期。若地方实施资料不足，或合法规则与机构执行记录冲突，保留两个断言及待核原因。已发生的拒绝、违规或申诉依自己的证据入人物账本，规则引擎不得改写为依法应当发生的结果。

### 阶段 D：判定个人暴露

每个渠道拥有自己的状态、证据和时窗。灾害直接暴露可发生于未获知风险时；媒体和家庭联系另记什么时候收到消息。家庭传导核对关系边在当时是否成立、实际往来与转移方向。例如当时未共居的成年子女可以通过汇款间接受影响，两人使用不同地点，家庭财务转移保留同一个事件 ID。单一 `confirmed` 不得覆盖同一节点中的其他未知渠道；人物明确没有在场，只能排除该在场渠道。

### 阶段 E：生成机制候选与替代路径

机制依据已有状态与环境生成。暴露渠道匹配时，LLM 生成可能结果、尝试失败或维持现状的候选。已排除的渠道停止产生该通道的状态增量。有资料缺口时保留待核条件和可行的替代路径。同一候选集明确哪些选项互斥、哪些可以并行。

- 有匹配总体、地区、队列和测量口径的外部数据时，使用校准后的条件分布及其误差区间。
- 有研究支持方向但不支持具体个体概率时，仅声明方向性候选和研究范围，不伪造精确数值。
- 没有合适数据时，标记 `synthetic_assumption` 并将现实概率保留为空。需要按指定比例运行测试时，单独保存情景权重及其设定依据。
- 每个候选保留是否采用、选择依据、触发条件、来源、目标维度和关键替代解释，供回归评测复查。
- 在可行集中区分同一决策的互斥结果与能够并行的经历。排队、通勤、多地点、单位许可和照护责任需要占用实际日程或预算；并行事件合并资源一次后才允许一并写入。

### 阶段 F：状态投影与人物视角

人物事件采用有效时间 `valid_time`，档案登记使用 `recorded_at`，来源公开时间单独登记。人物 `known_at` 绑定获知者、信息、渠道和时间精度。状态增量记录观测、抽样、规则推导或合成等来源，回忆和解释记录角色视角，反事实与未来情景记录适用分支。人物可以迟知、误记、沉默、拒答或无情绪改变。同一事件可跨日期作用于家庭成员。死亡结束本人后续行动，家属照料责任、追忆或遗产处置在各自的时间轴延续。

### 阶段 G：投影成图并验证

生成运行从候选中按风险过程或声明的情景规则采用事件并分配 `event_id`。图编辑 LLM 可直接提交人物图的修改、拆分、合并或撤销，系统持久保存以指定父修订派生的子分支修订，并沿依赖重算后继。所有受影响的共享事件、参与者状态、知识记录与快照同步验证。时间、地理、关系、资源硬约束和证据校验通过后，新修订方可用于默认投影。失败的修订与诊断保留可追溯，父修订和已有问卷快照仍可回查。总体分布、轨迹转移和群体异质性另按目标数据校准与验收。反事实运行保留独立分支和介入设定。 [图修订与运行契约](全链路设计复核与统一契约.md)

## 3. 可实现的字段契约

字段名是 v1 的概念契约，具体序列化可映射到平台 schema。不得删去事件来源和人物暴露证据而只保存自然语言结论。

### 3.1 暴露记录

```json
{

  "person_id": "P-7",
  "historical_node_id": "DIS-WC-2008",
  "historical_node_version": "1.0.0",
  "world_version": "WORLD-EXAMPLE-1",
  "graph_revision_id": "REV-P7-0001",
  "branch_id": "BRANCH-P7-BASE",
  "snapshot_id": "SNAPSHOT-P7-0001",
  "as_of": "2009-01-01",
  "archive_as_of": "2026-11-20",
  "status": "potential",
  "channels": [
    {
      "channel": "household",
      "status": "potential",
      "relationship_ref": "relation_active_on_2008-05-12",
      "contact_event_id": null,
      "known_at": null,
      "evidence_refs": ["family_event_ref"]
    }
  ],
  "origin": "synthetic",
  "person_location_refs": [],
  "spatial_match": {"subject_id": "P-7-RELATIVE", "status": "matched", "precision": "county"},
  "time_match": {"date": "2008-05-12", "precision": "day"},
  "intensity": {"value": null, "unit": null, "source_id": null},
  "evidence_refs": ["family_event_ref"],
  "reason_codes": ["RELATIVE_RESIDED_IN_AFFECTED_COUNTY"],
  "confidence": "unscored",
  "unknowns": ["housing_damage", "family_injury"],
  "prohibited_inferences": ["birthplace_does_not_prove_presence"]

```

逐渠道保留 `confirmed|probable|potential|excluded|unknown`，顶层 `status` 供筛查。只有所有适用且与本次任务相关的渠道均已排除才可返回顶层 `excluded`。匹配依据可信度、角色获知和渠道状态分别记录。`channels[].channel` 允许 `direct|household|school|work|service|network|media`。空间匹配保存匹配主体、结果和地理精度。家庭传导可由亲属位置匹配支持，焦点人物的位置仍按本人的记录判定。`confidence` 为 `high|medium|low|unscored`，分级依据随记录保存。`origin` 标明来自合成还是经授权的个体资料，候选采用状态记录在生成运行中。`confirmed` 表明在指定资料或图修订下具备渠道、时空及相应依据。直接观察须引用实际观察记录。现有消费方可在导出时读取渠道名称及完整逐通道记录。

### 3.2 机制候选

```json
{
  "candidate_id": "CANDIDATE-P7-WC-HOUSEHOLD-1",
  "person_id": "P-7",
  "exposure_id": "EXPOSURE-P7-DIS-WC-2008-1",
  "mechanism_id": "MECH-FAMILY-CARE-LOAD",
  "candidate_kind": "pathway",
  "mediators": ["family_injury", "care_demand", "work_schedule_change"],
  "moderators": ["household_labor", "insurance", "kin_network", "mobility_capacity"],
  "conditions": ["family_member_injury_confirmed"],
  "candidate_event_types": ["TEMPORARY_CARE_CHANGE", "WORK_INTERRUPTION"],
  "state_deltas": [],
  "probability": {"value": null, "basis": "uncalibrated", "interval": null},
  "scenario_weight": null,
  "evidence_status": "mechanism_hypothesis",
  "source_refs": ["study_ref_1", "family_event_ref"],
  "selection_reason": null
}
```

`candidate_kind` 包含 `pathway|no_direct_effect|no_action`。候选事件类型记在 `candidate_event_types`，选用后将候选记录和实际写入的 `event_id` 关联。图的 `branch_id` 标识已经持久保存的分支，反事实是该分支的运行目的。经验概率的依据为 `matched_data` 或 `uncalibrated`，实验比例单独放在 `scenario_weight`。证据引用保留 `mechanism_hypothesis|synthetic_assumption|population_observation|person_observation` 等支持类型。`no_direct_effect` 仅限定指定直接通道，家庭和媒体等路径仍按各自证据判定。

### 3.3 状态增量

候选状态增量携带 `candidate_id`、影响主体、维度 ID、前状态引用、预期变化、有效区间和依据。采用后的增量绑定 `event_id` 和 `graph_revision_id`，注明计量口径、参与关系、暴露与来源、确定性及修订路径。共同支付和损失按共享交易结算，各参与者只读取各自增量。摘要、传记和一次问卷作答按同一版本和授权时点投影。

## 4. 环境约束 C 的计算层次

环境约束 `C` 通过版本化查询函数计算。

```text
C_world(时点, 地点, 世界资料版本) → 当期环境与制度
C_person(人物快照, 当期环境与制度) → 可及机会、资格、供给和资源约束
Exposure(历史节点版次, 人物快照, 接触渠道, 来源) → 匹配依据与逐渠道判定
```

只有校准数据支持时才计算概率。节点和个人状态的最小空间时间单位由来源精度决定。省级人口统计支持省级刻画，县级灾害图支持县级匹配。个人在场结论需要定位与接触依据，未知定位保留未知。

同一人物可以在多个节点中：现场暴露、家人暴露、单位暴露、媒体暴露、政策资格暴露、接受援助或无可识别暴露。相互重叠节点还要共用损失账本，避免一个收入下降被“地震”“企业停产”“家庭迁移”重复累加。

### 4.1 人物可采取的行动与规则生效

| 核查环节 | 输出与用途 |
|---|---|
| 法定资格 | 规则 ID、适用主体、当期地方实施版本、具备/缺失材料、资格状态。按规定应有资格时允许存在实际被拒、等待补件或申诉。 |
| 现实供给 | 服务点与容量、可达路线、费用和等待时间、是否有无障碍或语言服务。供给可用、拥堵、暂停或未知。 |
| 人物获知 | 来源渠道、首次获知的时间精度及当时理解。未获知的人可以客观具备机会，也可能由监护人或经办方代办。 |
| 意愿与代理 | 个人、家庭或监护人当时谁可以决定，现实备选、时间冲突、预算与照料约束；自动适用场景记为 `not_applicable`。 |
| 申请或接触 | 办理窗口、申请、受理、补件、审核、撤销及拒绝的存在与时间。免申请/自动划拨场景保留规则和自动处理记录。 |
| 兑现与持续 | 批准、实际服务、拨付到达的主体与账户和时点，复核、续期及中止。资格时段与实际领用时段独立。 |

机构规则按有管辖权的地点、机构、事项和日期定位。对已经公布但未来才生效的条款，可影响人物获知后的计划；旧版账本要继续使用行动当日有效版本。追溯计补只改变核算区间；批准前的收入账和人物当时回答按本人的实际到账及知识快照保留。

## 5. 机制链中的“影响”如何操作化

### 5.1 影响不是单一因果边

建议用分阶段有向图表示候选关系：

```text
事件/政策节点
  ├─ 空间/资格/职业/关系匹配
  ├─ 实际暴露与强度
  ├─ 初始资源、健康、照护义务、网络、预期
  ├─ 中介：住房/工作/学校/现金流/服务/关系/信息/风险判断
  ├─ 行动与未行动：迁移、留守、求助、培训、劳动供给、沉默
  ├─ 结果：状态改变、无改变、受益、损失、恢复/持续影响
  └─ 记忆：当时知识、后续回忆、当前解释
```

每条边的元数据应包含：`edge_id`、适用人群/地区/时段、先决条件、支持来源、证据状态、可能混杂因素、替代解释、预期时间窗、个体是否可观测、参数是否有校准依据。下列分类至少要分开：

| 边类别 | 例子 | 生成器做什么 |
|---|---|---|
| `verified_rule` | 政策明文的资格/有效期 | 可用于资格约束，不推断实际办理 |
| `population_association` | 某调查中父母失业与某子群平均结果相关 | 用于候选分布/异质性验证，不套到个体 |
| `identified_effect` | 有清楚识别设计和适用范围的研究估计 | 在该研究人群/期间使用区间与假设，外推要单列 |
| `mechanism_hypothesis` | 受灾 → 迁居 → 通勤改变 | 可生成多分支，标为待检验机制，不报虚假系数 |
| `person_observation` | 个人记录证明参与安置或下岗中心 | 作为人物事实输入，不重新由模型推断 |
| `synthetic_assumption` | 没有个体资料时 LLM 提出的家庭选择 | 仅用于合成分支，保留生成理由与随机设置 |

### 5.2 时间与状态投影

不要让一次性冲击只改变“当年心情”。每个事件分别支持：

- `onset`、`duration`、`termination`：单日冲击、数月过渡和多年政策后果分开。
- `immediate_delta`、`recovery_delta`、`persistent_delta`、`memory_delta`：急性变化、恢复、可能持续影响和后来叙事不是同一个状态层。
- `valid_time` 与 `known_at`：人物当时不知道后来的政策效果；回忆也不能把后见之明写成当时知识。
- `affected_subjects`：事件可影响本人、配偶、父母、子女和工作团队，但每人有独立暴露证据和视角。
- `shared_cost_ledger`：家庭共同损失不在多个家庭成员记录中重复计为多个家庭损失；个人状态仍可以分别描述。

状态更新是候选，不是自动结果。例如“房屋损坏 → 迁居”需要迁居位置、产权/租住、可用住房、照护关系和政策安置条件；若这些字段缺失，只能说迁居是候选路径。

### 5.3 事件交叠与归因

同一年可以同时有地震、企业调整、家庭疾病和政策变化。系统建立 `co_exposure` 而不是让每个节点重复解释同一结果：

- 记录时间重叠、共同地点、同一家庭/工作组和共享资源；
- 区分直接损失、一般经济趋势、补助转移和测量变化；
- 对没有独立资料的多重因果保持“多候选归因”，不强求一个唯一原因；
- 若有负控组/识别模型，保存其定义、样本差异和识别假设；
- 人物自我归因和研究者机制标签并列保存，彼此不覆盖。

### 5.4 从研究样本移植机制

1. 读研究前先确认暴露单位、分母、结果和观察窗口。若住址仅定位到县，同县未出勤儿童和在场儿童的学校变化不可由同一个接触强度生成。
2. 对观察样本同时登记存活、返城/留居、是否被抽中及应答/流失条件。历史暴露强度有可能同时改变生存和后来进入研究的机会。以大饥荒后幸存者研究为例，应将“调查时仍存活样本的健康关联”用于对应条件下的校验，逐年死亡与迁出另走相应风险和来源。 [历史饥荒与幸存样本研究](https://www.nber.org/system/files/working_papers/w14917/w14917.pdf)
3. 年龄、时期和出生队列满足准确的线性关系。记录可解释的年龄阶段、地区或机构时点差异和队列条件，经验模型必须说明识别假设；报告至少一套替代假设下的变化。单一出生队列或横截面不能识别三者各自的作用。 [年龄、时期与队列模型模拟研究](https://www.demographic-research.org/articles/volume/30/11)
4. 把校准对象写在规则里，例如 `实际收到护理服务的参保老人`、`试点城市特定时期的调查样本` 或 `回城且受访的知青`。外推到另一地区、民族、政策和年份时先确认分母与定义可对齐，再保存差异和敏感区间。无可用数据时，分支保留定性方向或明确标记的情景权重。

## 7. 从 440 维度字典映射到事件机制

一条事件通道至少连接四类维度：

1. **位置/时间与资格：** `TIME`、`GEO`、`ORIGIN`、`ETHNIC`（仅来源确有分类时）。
2. **输入资源/能力：** `BODY`、`FUNC`、`HEALTH`、`ASSET`、`DEBT`、`CAPITAL`、`KNOW`、`LANG`。
3. **行动机会与关系：** `EDU`、`WORK`、`CAREER`、`MOBILITY`、`WELFARE`、`HOUSING`、`HOUSEHOLD`、`PARTNER`、`SOCIAL`、`COMMUNITY`。
4. **主观/观察结果：** `AFFECT`、`MENTAL`、`BELIEF`、`GOAL`、`SELF`、`MEMORY`、`SURVEYCOM`、`SURVEYRESP`、`PROV`。

生成器只更新存在可解释通道的维度，不要求一次事件把整套 440 条记录全部填满。未影响、没有测量、资料缺失、人物拒答和不适用必须保留不同编码。节点关联的维度族是候选范围，实际 delta 需经过人物条件、路径分支和证据检查。

## 8. 机制验收与误差账本

每批次除了普通事件一致性，还要报告以下专门指标。

| 指标 | 定义/检查 | 最低要求 |
|---|---|---|
| 暴露来源完整率 | 有 person-level exposure 的事件中，存在匹配依据/证据引用的比例 | 100%；无证据时应是 unknown/potential，不得伪装 confirmed |
| 宏观到个人误写率 | 未暴露或仅有宏观统计的人物，被写成亲历/受伤/下岗/享受服务的比例 | 目标为 0；逐条抽查 false-positive |
| 资格误判率 | 不符合规则有效期/地区/身份者被提议为直接适用事件的比例 | 逻辑门槛错误必须阻断，并记录规则版本 |
| 状态增量可追溯率 | 每个已采用的增量可回查前状态、来源或假设、有效期、事件和图修订的比例 | 100% |
| 候选路径覆盖度 | 每个关键节点的直接暴露、间接暴露、未接触或无影响及不同应对路径 | 在条件允许时保留无影响或保持现状对照，由目标群体审阅边缘路径 |
| 多重归因重复率 | 同一家庭/同一损失被重叠节点重复加入收入、资产或健康账本的比例 | 目标为 0；共因节点合并审计 |
| 经验概率校准 | 有匹配真实数据时按地区/时期/队列比较转移概率与误差 | 只有样本与口径可匹配时报告数值；否则标不可评估 |
| 人物知识越界率 | 作答引用在 `response_at` 尚未获知或未获授权披露的信息的比例。后补录和较晚的角色获知要分别检查 | 目标为 0。固定图修订、作答时间与归档视角回放 |
| 资格、供给与到账误合并 | 将申请、审批、缴费、可及、支付和已使用任意两环无依据地合并 | 对确定性反例全部阻断；分别报告各环缺失率与未知原因 |
| 角色错配率 | 机构级或接收地群体的结果被施加给另一种暴露主体 | 对知青本人、接收家庭与接收地学生分别设预期，不跨角色写入 |
| 可证伪性与可重放 | 固定其余输入，只改变地理、日期、机构版本、当期家庭关系或来源版次之一 | 该条件依赖的分支应改变；普通日程和无关状态无差异 |

误差账本记录历史节点、候选和受影响的事件标识，附地区、人群与时期、预测路径、实际或基准路径、证据版本、严重度、发现方式、修复的图修订和回归结果。验收使用独立规则、时空约束、来源和分布对照。

## 9. 系统集成顺序

1. **先补领域日历与地点索引：** 历史节点绑定有效时间和版本化行政地理；只添加有来源节点，标注高/中/低覆盖。
2. **再连人物位置/关系快照：** 生成器必须知道“这个人在此时可能在哪里/跟谁有关”，不能只有籍贯和出生年月。
3. **建立资格/暴露规则服务：** 规则返回状态、条件与缺口，而不是是/否二值；没有资料返回 `unknown`。
4. **开发机制模板：** 灾害冲击、企业收缩、教育制度、医疗保障、人口迁移等各有不同输入/分支/输出，不共用一个笼统“事件影响系数”。
5. **接入 LLM 生成与图编辑。** 生成运行保存未采用的机制候选。图编辑 LLM 直接提交变更，持久保存子分支并重算受影响的后继。程序负责自动校验、原子发布及版本回查。
6. **用独立调查/研究样本校准：** 按目标主题、地区和队列对照；不把代表性不明的调查关系当作全国参数。
7. **盲测及持续回归：** 新来源/模型/提示/机制发布时，跑规则、暴露误写、分布、机制、知识时间和问卷效度检查。

## 10. 历史情景案例

以下 26 个主题案例与 2 条跨节点履历展示合成人物在不同历史条件下的候选路径、对照路径和写入校验。案例中的 `historical_node_id` 对应目录的事件、口径和原始来源。 [历史节点目录](历史节点与环境暴露目录.md)

### `DIS-WC-2008` 汶川地震：直接灾害、家庭网络与重建并行

国家重建规划记录灾后住房、教育医疗、交通、产业、就业社保、生态文化和人口安置；国家条例还要求调查受伤/伤残、住房、公共服务、生产设施和环境承载能力。六波 CGSS 的研究报告主观福祉影响近十年、政策可恢复部分收入/健康/就业但未消除家庭解体相关的福祉损失；这是有特定样本和识别设计的研究结果，不可下放为每位受灾者结论。[总体规划](https://www.ndrc.gov.cn/xxgk/zcfb/qt/200809/t20080924_967737.html)、[灾后恢复重建条例](https://xzfg.moj.gov.cn/front/law/detail?LawID=278)、[六波 CGSS 研究摘要](https://pubmed.ncbi.nlm.nih.gov/36531932/)

| 阶段/通道 | 需要检索的事实 | 可提出的路径分支 | 目标维度族 | 验证/不确定性 |
|---|---|---|---|---|
| 震前位置与保护条件 | 当日居住/务工/上学地点、建筑类型、预警、家人所在位置 | 在场受灾；临时外出而未直接受灾；在周边但房屋损失有限；人在外地但亲属受灾；无法定位 | GEO;ENVIRON;HOUSEHOLD;EDU;WORK;MOBILITY | 地震目录/烈度/县级调查只到来源精度；籍贯和居住地不自动证明当时在场 |
| 冲击与安全 | 伤情/死亡、房屋受损、学校停摆、道路/供水/通信、财产和农地 | 无伤但流离；伤后康复；近亲丧亡并增加照护；住宅轻损且原地居住 | HEALTH;FUNC;HOUSING;ASSET;HOUSEHOLD;MEMORY | “受灾人口”不等于个体损失；无灾情个案时不能补造伤情、金额或创伤 |
| 救助与过渡安置 | 安置点、临时住房、医疗/心理救助、补偿资格、家庭重聚 | 留在安置点；依亲迁出；多次迁居；未获得/拒绝某项救助；得到救助但仍有长期损失 | HOUSING;WELFARE;HOUSEHOLD;HEALTH;MOBILITY;COMMUNITY | 需有安置名单/家庭档案/自述等个体证据；政策资格和实际领取分开 |
| 教育、劳动与家庭恢复 | 学籍连续性、单位/岗位、农业/旅游/建筑经营、家庭劳动供给、保险和转移 | 返校/转学/辍学后复学；原就业恢复/行业转移；以工代赈/建筑机会；照料导致暂时退出劳动；无明显就业变更 | EDU;WORK;HOUSEHOLD;INCOME;WELFARE;LIFECHANCE | 学校和行业冲击按地点和时间验证；不能把重建工作机会强派给灾民 |
| 中长期分化 | 重建位置、次生地灾、住房与公共服务质量、迁移意愿、关系与心理/身体随访 | 迁出寻求安全/就业；留下并利用新服务；有迁移意愿但受照护/资产限制留下；短期恢复但长期关系/健康影响仍在；未报告持续影响 | GEO;HOUSING;HEALTH;MENTAL;PARTNER;COMMUNITY;MEMORY;GOAL | 957 人次区域调查只代表所抽 12 个地灾区；CGSS 全国样本估计不能指定某人的个人效应。来源差异与幸存者/追踪流失应记录 |

**四条示例主线，全部为合成情景而非真实人物。**

- `WC-A 直接受损`：在高烈度区居住且房屋严重损坏 → 安置/重建资格待核 → 迁居/工作与子女学校通勤变化 → 收入和照护状态按家庭事件分别更新 → 人物后来可能记得震害，也可能只保留片段。无伤亡/财产金额证据时不生成精确伤情或数字。
- `WC-B 家庭间接暴露`：人物当日在成都工作，父母居住在受灾县 → 家庭电话和探亲提供信息接触 → 返乡照料可能与工作冲突 → 亲属损失/住房状态仍取决于家人事实。不能把成年子女直接标成震中幸存者。
- `WC-C 重建机会`：来自其他地区的建筑工人经雇佣关系迁入重建县 → 工资、工期和住宿风险按工作证据记录 → 有人增加收入，有人项目完工后再次迁移。不能把“参加重建”当受灾或救援身份。
- `WC-N 无直接效果路径`：人物离开受灾区且没有家庭、工作或救助接触。无消息渠道时只保留普通日程；若另有新闻接触证据才补记知晓时间。用作负控时检查健康、迁移或态度保持原有轨迹。

### `POL-EMP-1998` · `POL-NE-2003` 东北国企下岗：单位冲击、政策保障与家庭传导

国家统计局给出的 1998–2002 国企下岗累计数和包含此前累计数是**全国口径**，不能称为东北人数。东北振兴政策又增加了资源型城市转型、就业和社会保障背景。研究发现失业对劳动者健康会随政策和时间变化；另有自然实验研究报告父母下岗的不确定性与儿童体重增长在性别/样本上不同。以下路径须同时保留全国宏观背景和东北市县/企业证据。[国家统计局下岗报告](https://www.stats.gov.cn/zt_18555/ztfx/qzxzgcl60zn/202303/t20230301_1920385.html)、[东北振兴政策回顾](https://www.ndrc.gov.cn/fggz/fgzy/xmtjd/202107/t20210721_1291202_ext.html)、[长期健康研究摘要](https://pubmed.ncbi.nlm.nih.gov/39615962/)、[代际体重研究摘要](https://pubmed.ncbi.nlm.nih.gov/31330471/)

Giles、Park 与 Cai 使用 2001 年末五城市劳动力调查回溯 1996–2001 年就业调整，发现样本中公共援助覆盖有限，许多离岗者依赖家庭成员支持。把“中心与公共保障”“配偶增劳或其他亲属支援”“实际可支配收入”做成并行路径。城市样本包括沈阳等地，只有落到相应研究对象与观察窗的结果可以校准。 [五城市劳动力调查研究](https://www.cambridge.org/core/journals/china-quarterly/article/abs/how-has-economic-restructuring-affected-chinas-urban-workers/B83FFD89015156FDBF30D0DBA8B27780)
| 阶段/通道 | 需要检索的事实 | 可提出的路径分支 | 目标维度族 | 验证/不确定性 |

**三条示例主线，全部为合成情景而非真实东北居民。**

- `NE-A 保障中心后再就业`：某地国企普通工人离岗 → 资格/中心参与有证据 → 培训/基本生活费过渡 → 本地服务业再就业、工资下降 → 家庭消费和孩子教育投入改变。不得只凭年龄或东北籍生成“进中心”。
- `NE-B 家庭间接冲击`：父亲面对潜在下岗、家庭收入不确定，但个人未被裁员 → 孩子可能察觉家庭压力并改变消费/健康/学习，也可能并无可识别变化；只有同一研究任务有数据时才校准性别/队列差异。
- `NE-C 弱暴露/不同受益路径`：同一城市另一家庭成员在新扩展行业工作、岗位需求上升，家庭可能从产业转型受益；但仍可能受公共服务、迁移或家庭照护约束。作为反事实，避免把城市/地区宏观衰退写成所有居民相同的个人损失。

### 唐山地震与单位复工

`DIS-TANGSHAN-1976`。合成情景中，工人震时住在唐山工矿社区，厂房受损后停工，两名家庭成员暂住不同地点。

- **推演与写入**　先写转移与暂住，再按实际复工日期结束停工段。工资、伤病和照料来源独立核查。
- **对照路径**　同厂同事震时出差，可因厂房停工而停薪或转岗，现场亲历维持未知。

### 高校扩招与第一份工作

`POL-EDU-EXPANSION-1999`。两名考生同年参加高考，分别面对不同省份招生计划、成绩与家庭预算。

- **推演与写入**　生成报名、录取、报到、毕业，再查询毕业地同时期的岗位。师范或工程专业的候选职业依据当时地区需求。
- **对照路径**　一人有录取通知但因成本选本地职校，另一人入学后毕业求职延迟。招生增长率不写作录取概率。

### 台湾集集地震与就学

`DIS-TW-CHI-CHI-1999`。合成家庭居住在南投，住房受损，孩子学校也有借校记录。

- **推演与写入**　以两个事件更新暂住地址与教学地点，再重算接送和照护。复建后核对是否回原聚落和原校。
- **对照路径**　房屋可住但学校受损时，家庭保持原住址，只调整通学。采用台湾当地资料与称谓。

### 三峡库区移民与家庭安置

`MIG-THREE-GORGES-2001`。合成农户有库区清册和分批安置方案，原来由老人带孩子、成年人种地兼务工。

- **推演与写入**　分别记录补偿核定、支付、迁居、分配或取得生产资源、转学与异地就业，允许家庭分批抵达。
- **对照路径**　就地后靠则更可能保留原有通学或互助关系，异地安置也可延续原乡亲属联系。

### 新农合与一次住院

`POL-NCMS-2003`。同县两名居民有不同参合状态和就诊机构。系统先查县当年是否试点，再查参合、就诊和费用规则。

- **推演与写入**　把住院总额、个人先垫付、报销申请与到账写成不同记录，再重算家庭净支出和借款。
- **对照路径**　参合但未就诊时无报销事件。就诊增多与自付下降在现有研究中需要分别检验。

### 青藏铁路与异地可达性

`INF-QINGHAI-TIBET-2006`。合成人物在通车后仍需从村到站，再从拉萨站换乘到就医或学习地点。

- **推演与写入**　查询当年站点、班次和接驳，比较耗时、预算和是否有人陪同。实际购票或货物到货才写出行或交易。
- **对照路径**　一个家庭可以从货运到货受益但多年未乘车。访亲、就学、就业各自判断。

### 南方冰冻与春运

`DIS-ICE-2008`。合成务工者的车次受停运影响，原籍家中同一时期存在停电。

- **推演与写入**　旅途延期和家庭用电中断分别入账。前者改变返乡与返岗时间，后者可增加照护和取暖开支。
- **对照路径**　旅客已改走其他路线可按时到达，家属仍可受到停电影响。

### 金融危机与提前返乡

`ECON-CRISIS-2008`。合成外出务工者有外向型企业减班和实际提前返乡记录。

- **推演与写入**　区分减班、停薪、解除关系和返乡，针对放假、复工、跨省再就业保留不同终点。
- **对照路径**　同乡正常探亲后回原单位，虽也返乡，保留原劳动关系和工资。

### 随迁子女异地升学

`EDU-MIGRANT-EXAM-2012`。合成家庭已跨城定居，孩子在当地连续就读，但父母缴费记录不完整。

- **推演与写入**　查该省该年中考与高考分别采用的条件。资格未知时保留补材料、回原籍备考或选择其他教育路径。
- **对照路径**　同城两人可以分别获准中考与高考，留守、迁移、录取仍要依据各自事件。

### 易地扶贫搬迁与生计接续

`POVERTY-RELOCATION-2015`。合成家庭经当地项目识别后选择搬迁。成年人继续跨地务工，老人照护儿童。

- **推演与写入**　按入住、转学、诊疗位置、就业和土地经营分别更新。就业波动与住房改善可同时存在。
- **对照路径**　已纳入范围但因照护和耕作留居，走原地扶持或措施待核路径。

### 香港山竹与不同暴露

`DIS-HK-MANGKHUT-2018`。合成香港居民住在高层，平日需搭渡轮上班，风暴期间班次取消。

- **推演与写入**　以可匹配的班次登记通勤受阻与单位请假；配电中断和入户水浸分别查询。
- **对照路径**　同街低层商户有进水损失，高层居民可能只受出行影响。潮位观测保留区域口径。

### 澳门客流冲击与服务业

`ECON-MO-TOURISM-2020`。同一澳门旅游业年份，合成酒店员工依赖访客，另一位餐饮员工主要服务居民。

- **推演与写入**　用企业客源和班表刻画减班、转岗或继续上班。跨境劳动者另查口岸和实际通勤日期。
- **对照路径**　企业降客流可保基本工资，家庭现金流未必变化。客流降幅不能当工资变动。

### 郑州暴雨与通勤路径

`DIS-FLOOD-2021-ZZ`。合成通勤者当天下午经过积水路段，另一人在同城居家，家庭地址未证实受浸。

- **推演与写入**　地点和时间匹配才写改道、滞留或缺班，并以实际财产和工时记录更新损失。
- **对照路径**　居家者可能只有亲友联系或停电经历。不能由同城居住生成特定地铁或隧道经历。

### 跨省就医与家庭周转

`MED-CROSSPROV-2016-2022`。合成异地养老者在外省就医，核到当年的备案、联网机构和费用类别。

- **推演与写入**　以就医地目录、参保地待遇规则生成账单候选，实际结算后更新个人自付，再决定借款或复诊安排。
- **对照路径**　网络故障先垫付后手工报销，使用同一费用事件去重。早年住院不套用后来门诊规则。

### 加拿大华人移民限制与分居

`MIG-CA-1923`。合成夫妻分别住在加拿大和广东，拟在 1920 年代办理团聚。

- **推演与写入**　按当时居住地和入境类别审查申请。只有申请结果或合成分支决定是否构成分居延长，再更新汇款和子女照料。
- **对照路径**　已同住家庭不生成新增分居。1947 年废止后，团聚仍需办理、可负担行程和意愿。

### 玉树地震与农牧家庭恢复

`DIS-YUSHU-2010`。合成家庭在玉树州的住所受损，牲畜损失和学校停课待核。

- **推演与写入**　按当地安置记录更新住处。分别检查牲畜损失、牧场可达性、复课与照料。住房复建后，家庭仍可能转为兼业。
- **对照路径**　牲畜无损而道路中断时，保留资产存量，另记运输和销售。宗教场所复建与个人参与分开。

### 非典期间的停课与家庭照料

`PUB-SARS-2003`。两名合成学生就读于同城不同学校，仅一人的班有停课通知。

- **推演与写入**　按班级和日期登记停课及复课，查在家学习、实际照料安排和家长工时。个人接触与就诊事件独立保存。
- **对照路径**　另一校仍授课，人物可只有校园管理变化。家庭信息和教学方式按 2003 年可用条件核对。

### 食品召回、筛查与消费选择

`PUB-MELAMINE-2008`。一户合成家庭买过涉事品牌，批次和实际食用待核。另一户仅从新闻获知召回。

- **推演与写入**　第一户维持摄入待核，实际筛查后记录就诊及费用。第二户可能改买其他产品，变更消费记录。
- **对照路径**　无异常只写该次筛查结果。品牌、出生年份和筛查行为各自不足以确认摄入或诊断。

### 新农保试点与老年劳动

`POL-NRPS-2009`。合成老人所在县已试点，与成年子女共同经营农地，领取日可核。

- **推演与写入**　分开登记参保、缴费、待遇核定与到账。到账后家庭可减少部分农业工时、调整消费或维持分工。2014 年后按城乡居民养老保险并轨版次重查。
- **对照路径**　同村未达当期领取条件的人只写参保缴费。家庭转移和工时变化需要相应证据。

### 婚育政策版本与照料安排

`POL-FERT-2016-2021`。两个合成家庭面对不同时点的生育政策，一户希望再生育，另一户希望推迟。

- **推演与写入**　按生育时点查询生效版本和地方服务。出现出生事件后，再分别更新家户成员、照护者、托育申请和工作安排。
- **对照路径**　家庭可维持原有意愿。政策资格、实际生育、登记与托育获得分别判断。

### 知青下乡与两地教育机会

`HIST-SENDDOWN-1968`。合成城市青年原读高中，随单位所在城市安排赴某县农场，后来通过招工办妥返城。其接收地邻村有一名同龄学生，两人起初没有日常来往。

- **路径**　城市青年先结束原学校正式就读区间，再开始在当地劳动和居住的区间，返城申请、批准、原址到达和首份城市工作独立。接收地学生只有在已建立的具体补课或同班教学关系下才新增学习接触，年月由学校与往来记录限制。
- **对照路径**　城市青年有亲友支持仍可能长期留乡；邻村即使处于同县，也可因通学和接触条件维持原学习轨迹。县级接收强度可以校验群体差异范围，不能自动赋予个人技能或长期收益。

### 海河洪涝中的住房、通勤与家属援助

`DIS-HAIHE-2023`。合成一家人的老人居住在有转移通知的村，子女在同一流域另一座城市租住；村内房屋、家庭耕地和子女所在单位分别记录地点。

- **路径**　按最低可核地理单元匹配老人实际转移及临时住处。子女经电话获知并支付临时住宿，自身记录家庭援助和相关预算变更，通勤只有道路本身确实中断才调整。耕地受损、房屋修缮和补助到账各自落到相应资产、交易及日期。
- **对照路径**　家属可仅代办材料，无共同搬迁；农地减产和住房同周受损可各记一次，针对同一维修款的地方补助与亲友代付通过支付账本核对，避免重复计入总损失。

### 追溯计补与真实可用的育儿资源

`WEL-CHILD-2025`。合成家庭的幼儿在 2025 年前出生、2025 年 1 月尚未满三岁，监护人年中获知政策并尝试办理。按当时适用的管理口径核对出生年月、儿童户籍、监护主体、申请时间和地方发放批次。

- **路径**　在资格账中写入覆盖月份与依据。在家庭财务中，获批后可记待收，确认到账日再增加可支配余额。问在政策公开前是否了解补贴时，按当时知情快照回答；问后来领到多少时，从实际到账或未知状态出发。
- **对照路径**　合规家庭可能错过首次申请期限、申报后补件或已通过但到账晚。获得补贴后是否换工作、增加托育或继续由家庭照顾，依资源、托位和当事人选择分别生成。

### 长护险服务能否替代家庭照护

`WEL-LTCI-2026`。合成失能老人居住在湖南，女儿每周投入固定照护时段。湖南方案要求具备条件的市州在 2026 年对单位职工、退休人员和灵活就业人员先启动，2027 年计划推动所有市州启动就业人员相关制度，2028 年逐步启动未就业城乡居民保障，已有试点另有过渡安排。为人物匹配所属市州和参保类别，核对实际启动和受理日期。 [湖南省实施方案](https://www.hunan.gov.cn/hnszf/xxgk/wjk/szfbgt/202609/t20260924_34071666.html)

- **路径**　当地正式纳入后完成相应评估，护理服务已有合同、护理时段与实际结算。家庭照护只在具体事项和时间可替代时冲减女儿的投入，体力帮助、情绪支持或医疗联络可继续。是否增加工作时间另查其雇主排班。
- **对照路径**　城区有机构名额而本人居住乡镇缺少可达服务，或当地尚未覆盖其参保类别。即使审批通过，同样可以因等待或本人偏好保留家庭照护。2026 年国家框架只进入规则索引，个体供给不能预填。
- **证据边界**　较早试点研究观察到部分老人更依赖机构和专业照护，且结果随老人群体和政策规定变化。以试点研究生成替代路径，再按本地护理项目、服务时数和家庭日程核验 2026 年以后是否实际替代。 [长期护理保险试点原始研究摘要](https://pubmed.ncbi.nlm.nih.gov/39172812/)

### 多节点履历验收

**跨省务工家庭的升学、居住与就医。** 合成家庭于 2011 年跨省务工，孩子随迁就读，老人保留原地参保，几年后赴子女住处养老。关联节点为 `EDU-MIGRANT-EXAM-2012`、`POL-RESIDENCE-2016`、`MED-CROSSPROV-2016-2022`。

- 按 2012 年后当地高考或中考规则核对学籍及父母材料，更新考试资格和实际报名 EDU.04。2016 年后另查居住证申领和签注，保留登记地 GEO.04 与常住地 GEO.03。老人于 2023 年异地就医时再查当期备案、联网机构及费用支付，更新 WELFARE.02。
- 孩子可因当地考种门槛回原籍考试，老人可先垫付再报销。不把居住证当落户，也不把这笔跨省结算回填到 2011 年。

**复工之后遭遇暴雨的通勤与收入。** 合成员工在 2020 年按单位批次复工，2021 年仍在郑州同一城市工作。其本人通勤受暴雨影响，同住家人的工作地点与路线不同。关联节点为 `COVID-REOPEN-2020`、`DIS-FLOOD-2021-ZZ`。

- 先依 2020 年单位记录结束停工区间。2021 年用实际路段与时窗更新通勤 MOBILITY.03，只有单位排班、工时和工资记录支持时才更新 WORK.05 和 INCOME.01。
- 缺班但薪资照发时保留原收入。若雇主停业与通勤受阻都能解释同一笔工资减少，保留两条归因及一笔损失。其他家人仅按本人的路线和工作记录更新。
