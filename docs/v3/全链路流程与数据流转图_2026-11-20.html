总体架构

契约、运行数据和人物输出分层

技术平台执行有版本的规则和风险过程。项目保存人生事件图与证据血缘。LLM 在有权限的子分支直接修订合成记录，自动重算和校验后再发布。

总架构图文本说明
  1. 来源注册生成可复查的世界资料、总体参数和人口样本。
  2. 仿真适配器生成初始事件图，LLM 在有权限的子分支直接修订。
  3. 领域依赖服务重算受影响事件和共享人物状态，校验通过才更新默认发布指针。
  4. 问卷服务固定图修订和人物视角快照。新模型、新数据或新题目需形成新的验收与发布版。

数据血缘与版本链

从源材料到一次问卷回答

同一份事实在不同阶段改变口径与用途。每次转换都要保留输入版次、资格和分母，最终答案需要能回到实际读取的人生图版本。

数据血缘图文本说明

来源 Artifact 标识可定位的材料和版次。Mapping/Claim 表达变量映射和支持或反驳的断言。PopulationFrame 和参数包定义抽样资格与估计口径。run_id 固定执行环境。graph_revision_id 固定人生图。release_id 固定已通过的发布集合。snapshot_id 固定查询时点、档案截止和角色投影。SurveyResponse 不改写人生图，只保存回答和其依据。

人口抽样到人生图

模拟入口与实际事件分开

生成流程的关键判别
  1. 目标总体和研究用途先于抽样器与语言模型。
  2. 存活截面入口不能把从出生无条件生成后筛人当作等价实现，除非条件分布、存活率和抽样权重验证通过。
  3. LLM 编辑可以直接应用到新子分支，但默认读取使用通过自动校验的已发布修订。

LLM 人生生成工作流

骨架确认是用户断点；之后的细节任务绑定所选图修订

LLM 负责理解用户选项、规划工具调用、生成细节与角色表达。仿真器负责候选风险和时序推进，来源工具负责提供可查材料，独立校验器负责判断能否发布。

LifeGraph 节点与边

事件图、时间序与重算依赖是不同结构

事件图读取规则
  • 尚未采用的 candidate_id 只是候选，不是实际人生事件。
  • 同一次共享事件使用一个 event_id，各人物仅保存其参与角色和状态增量。
  • 时间区间、时间精度、人物视角、证据及实际事件是否成立分别表达。

时点语义与回放

一条人生可以同时有发生、登记、获知与作答时间

回放示例

一次离岗发生在 2001 年，人物在 2012 年回忆错一年，档案在 2025 年补录。读取新的发布修订，可查询到经补录的 2001 年事实。按 2025 年前的 archive-as-of 回放则仍看不到补录。模拟 2012 年问卷只使用人物当时已知的内容和回忆。

生命周期与档案读取

以所用图修订和观察截止为准

直接编辑与父子版本

写入工作分支，校验后才成为默认可读版

事务边界文本说明
  1. 应用编辑之前核对父修订仍是调用时所见版本，重复提交按操作 ID 返回同一结果。
  2. 在同一 case 及所有共享事件参与人范围内定位依赖闭包，非关联记录保留旧版引用。
  3. 校验中间版本不得进入默认问卷检索。冲突、超时或数据不足的修订保留诊断状态。
  4. 校验通过后签发 release 指针，旧 release 与依其生成的问卷答案都继续可读。

历史世界如何进入个人路径

宏观史实不会自动成为个人经历

暴露判定的反例
  • 政策资格成立但服务无供给，不等于使用或到账。
  • 焦点人物在外地、家属在受灾地时，家属经历不能复制为本人直接暴露。
  • 省级受灾总量不提供个人县、镇或房屋损害事实。
  • 无事件影响可以是经过证据支持的候选结果，也可以只是未观察，不能互换。

从生活经历到记忆和叙事

一次经历可以对应不同人物的理解

问卷调用与人物视角

作答是观察记录，不是图编辑命令

三类问卷状态示例
  • 呈现状态记录已呈现、跳题、无资格或未呈现。
  • 回答状态区分不知道、记不清、无意见、拒答、主动中断和未产生作答。
  • 执行状态记录成功、阻断、超时或失败。统计分母依施测及执行状态确定。

档案库数字人对话

工具检索提供事实，角色模型负责自然表达

第一人称回答能给出自然对话体验。系统以稳定档案身份和角色视角限定模型可见信息；运行控制层仍将其视为带版本和证据的合成人物代理。

验收证据与发布边界

按指定用途核对各项证据

五类验收证据
  1. V0 结构检查模式、引用、查询、回放与访问范围。
  2. V1 逻辑检查时间、关系、资源、共享事务及生死边界。
  3. V2 总体检查指定抽样框的边际、联合分布和分析权重。
  4. V3 轨迹比较留出数据中的转移、次序及持续时间。
  5. V4 指定问卷任务按题组、总体、施测方式和预登记误差限，与独立真人样本比较。
完成 V0–V1 说明图结构与硬规则可用。只有独立总体证据支持时，才能报告 V2；只有指定追踪证据支持时，才能报告 V3；V4 还需要对应问卷任务的盲测和真人留出比较。

运行模式与职责边界

同一图契约，不同的执行语义

首次生成

锁定总体、参数和随机方案，产生首个工作图并校验后签发。原始请求和实际输出存入运行清单。

直接编辑

LLM 在父修订下编辑子分支，定位影响闭包，重算并自动校验。失败保留工作版，可继续修改。

持续发展

在世人物从观察截止日后追加未来事件。新证据改正过去时，另建新分支，旧版和旧答卷仍可回放。

情景与反事实

指定干预、适用世界和模型假设。保留情景权重，不把未经校准的探索比例写成人口概率。

只读回放

读取已存图产物和运行记录，不重新生成。旧版模型或资料若不可用，仍可读取原发布产物。

验收与回退

发布指针只切换到所需验收范围通过的版本。新版本失败可回退读取父版，错误修复不修改旧会话。

重点运行观测项
运行面保留指标触发检查
作业队列等待、执行时长、重试、取消、状态持续时间超时率上升、阻塞积压、重复消费
图写入编辑次数、影响闭包大小、校验结果、未解决冲突、版本增长高纠偏/撤销率、受影响切片权重漂移
来源和参数数据版次、许可、总体验证范围、风险集和参数误差来源撤销、新调查波次、政策规则变更
问卷结果呈现、回答、系统执行状态和证据引用的分群比例群体方差塌缩、错误类型漂移、跨题关联变化
