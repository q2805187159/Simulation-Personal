## 1. 节点的最小记录结构

每个 `HistoricalNode` 至少保存以下字段，并在增补地方节点时沿用相同结构。

| 字段 | 约束 |
|---|---|
| `historical_node_id` | 历史节点稳定标识，名称修订沿用原 ID，合并或拆分保留旧 ID 的映射 |
| `historical_node_version` | 单条目录记录的修订版本，引用时与 `historical_node_id` 配对。一次运行以 `world_version` 固定所用的目录、地理和制度资料版本 |
| `valid_time` | 有效日期、有限区间或未知时间及其精度。法律生效、地方实施、撤销、灾害发生分别记录 |
| `release_and_record_times` | 分别保存规范的成文、公开、生效、地方启用、制度工单可用和系统采录时间；历史快照可按日期重放 |
| `scope` | 国家、地区、行政层级、城乡、行业、机构或跨境范围；不把全国政策写成同日同效 |
| `local_implementation` | 地点版本、辖区层级、上位与实施文件、有效区间、受理机构、容量/排队/材料门槛与政策冲突状态 |
| `eligibility` | 只有符合年龄、地点、职业、家庭关系、在场时间或制度资格者才有直接暴露机会 |
| `exposure_channels` | 亲历、住房/工作受影响、学校、家庭成员、迁移、公共服务、新闻/网络、救援或记忆传承 |
| `mechanism` | 约束、机会、损失、转移、学习、关系变化、风险知觉或叙事/记忆通道 |
| `phase` | `shock` 冲击、`relief` 救助与恢复、`reconstruction` 重建/制度化、`memory` 后续记忆与再解释 |
| `affected_dimensions` | 关联维度字典中的 `dim_id` 或 `family_id`，表示候选影响通道 |
| `individual_evidence_requirements` | 指明可能需要的个体、家庭或机构记录及相应授权、观测精度和最低匹配条件。匹配结果记录在人物暴露记录 |
| `evidence_roles` | `world_event`、`population_observation`、`mechanism_hypothesis` 等支持用途。资格、所见渠道、证据强度及个人接触状态有各自字段 |
| `heterogeneity` | 地区、城乡、民族/语言、年龄、性别、家庭资源、职业、残障、迁移和政策执行差异 |
| `prohibited_inference` | 明确禁止从出生年、籍贯、民族、职业或新闻接触直接推出的结论 |
| `sources` | 官方法规/统计、原始调查或学术研究分别标注；保存访问日期和失效状态 |
| `calibration_scope` | 来源对象、纳入与流失机制、分母、时期和地区、观察窗口、估计对象、可转移条件与原始单位 |

## 2. 个体暴露判定链

直接处置、家庭传导、服务使用和后续获知分别计算。每个渠道只要求它所依赖的证据，未知条件和已经证实的局部事实可以并存。例如住处确实停电时，应记录停电，即使伤病状态未知。历史节点来自现实资料，合成人物中的在场和损失属于可复核的模拟账本。

```text
世界节点存在
  → 分渠道匹配地点、动线、机构归属及当期有效关系
  → 记录物理接触、服务使用或获知证据，保留各自日期
  → 政策机会另查资格、供给、得知、意愿、申请和兑现
  → 按机制与普通日程生成事件候选，区分采用、无变化与待核
  → 用 event_id 登记采用的事件，投影救助、重建、迁移、制度转换及恢复
  → 在人物知识与记忆快照中生成叙事和问卷作答
```

灾害统计中的“受灾人口”是群体层字段。个人级暴露还需查在场与移动轨迹、工作/学校地点、住宅损坏、亲属伤亡、资产和债务、医疗/救助、迁移、媒体接触与当时年龄。未受直接影响的人可以有新闻、救援、捐助、行业和政策暴露，也可以没有可识别后果。

## 5. 数据质量与验收门槛

- **来源门槛：** 每个宏观节点至少有一个法规/官方事件来源；涉及个人后果时，再加原始调查、纵向研究或地方材料，并注明样本范围。
- **空间门槛：** 灾害和政策节点至少细化到官方可支持的省、市、县或学校/行业层级；不能用省级受灾人数替代个人位置。
- **时间门槛：** 事件发生、政策生效、地方实施、个人获知、救助、恢复和回忆分别记录，允许日期区间和不确定性。
- **应付和实际执行：** 制度要求、机构解释、通知或实际办理结果分别留源。调研支出与账本采用确有证据的支付，允许欠薪、拒绝、等待、复核和补发。
- **证据边缘：** 来源仅支持史实或政策时，节点可进入目录，人物分支按合成情景提供。只有可核查的观察样本、分母和识别条件齐备时才写群体效应或可转移参数。
- **对照路径。** 对重要节点设置无直接暴露、未获得机会或采取替代行动等测试条件，验证生成结果随所用条件变化。
- **独立验证门槛：** 生成器不得用同一 LLM 生成历史事实、人物后果和验收结论；使用规则校验、独立资料检索、留出数据和专家/目标群体审查。
- **来源更新。** 法规、统计口径、灾情修订和学术结论进入新历史节点版次及世界资料版本。旧版保持可追溯。历史规则按所查有效时点与档案截止点加载。修订通过反向索引定位受影响的参数、暴露记录和事件依赖，在新子分支重算并校验，旧图修订和已保存答卷仍可回查。

## 6. 研究状态

本版包含 69 个节点。覆盖近代及当代部分事件，包含中国大陆、香港、澳门、台湾地区与美国、加拿大华人相关场景。逐节点触发、候选结果、对照路径及写入检查见[《历史暴露推演与个人路径机制规范》](历史暴露推演与个人路径机制规范_v1.md)。用户定义的总体范围覆盖全部地区和民族，具体时空细分由来源支持决定。历史政策、调查分布、地方服务或语言版本空缺时，在覆盖矩阵标记所缺字段和可用的上一级证据，按已证实路径自由度生成合成档案。更早时代的村镇资料、各民族内部及跨地差异和更多侨居辖区仍有较大覆盖缺口。学术资料的阅读层级和用途见[数据来源与覆盖矩阵](数据来源与覆盖矩阵.md)。
