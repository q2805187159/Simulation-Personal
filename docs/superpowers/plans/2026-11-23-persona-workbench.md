# 人物生成与档案问答升级

本文记录工作台、人物细节和问答的实现契约。前端仍通过 FastAPI 读取 PostgreSQL 中的图、细节和发布版本。

## 生成

- [x] 在骨架审阅之后，为合成事件生成带时间锚点的情绪、事件评价、记忆、倾向和表达特征。由规则约束分数范围和连续变化，由模型细化有依据的场景与表达。
- [x] 保留构造方法、所用模型、证据范围和缺失值。历史背景候选、出生和死亡使用各自的记忆语义。旧版档案允许没有量化字段。
- [x] 审查使用冻结的生成版本。修复后复查，发布版本固定骨架、细节和报告。

## 问答

- [x] 每轮从同一会话中提取有限的上文，识别指代和信息需求。先查时点内的事件索引，再按需查事件、记忆和人物状态。
- [x] 工具只读，由应用约束可访问的事件和字段。历史快照屏蔽未来信息，模型答案只能引用本轮取得的证据。
- [x] 会话可恢复。页面按需展开来源、有效时间、资料类型与工具轨迹。

## 工作台与验收

- [x] 工作区视图随 URL 恢复。浏览器返回、重载和草稿续接可用。聚焦当前任务，通过清楚的按钮层级、错误和忙碌状态反馈动作结果。
- [x] 提供模型密钥文件配置，真实模型经后端接入。本地 mock 保留为可复现测试路径。
- [x] 核验测试、真实模型生成与连续问答、PostgreSQL 读回、宽窄视口和旧档案。

事件检索与角色反思的分离参考 [Generative Agents](https://arxiv.org/abs/2304.03442)，跨轮引用和时间一致性验收参考 [LoCoMo](https://aclanthology.org/2024.acl-long.747/)。
